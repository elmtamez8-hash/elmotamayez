# Quickstart — كيف يُثبَتُ أنّ ٠٢٣ تعمل

ليست دليلَ تنفيذ. هي **ما يُشغَّلُ ليُقالَ إنّها تعمل** — وكلُّ فقرةٍ هنا تنتهي بشيءٍ يُعَدُّ أو يُقرَأُ على الشاشة، لا بانطباع.

## التجهيز

```bash
cd backend  && PHP_CLI_SERVER_WORKERS=8 php artisan serve      # الخيطُ الواحدُ يُفشِلُ بناءَ Playwright
cd frontend && npm run dev
```

بياناتٌ لازمة: كورسٌ **منشور** لمدرّسٍ **معتمَد** في مساحةٍ **مشارِكة**، وله مجموعتان (واحدةٌ بمقاعدَ وواحدةٌ ممتلئة) وفتراتُ توفّرٍ معلَنة، وطالبٌ **مسجَّلٌ في الكورس** ورصيدُه يكفي.

⚠️ **والفخُّ في الفخِّ**: `addWorkspaceMember()` تختمُ `users.last_workspace_id`، والبذورُ تختمُها لطلّابِها. طالبٌ حقيقيٌّ **لا يملكُ تلك القيمةَ أبداً** — لا التسجيلُ يكتبُها ولا الدخول. فأيُّ تجربةٍ لمسارٍ طالبيٍّ تُبنى ببذرةٍ تقيسُ شخصاً لا وجودَ له في الإنتاج، وخمسةُ منافذَ ماتت مرّةً بهذه الطريقةِ في ٢٠٢٦-٠٨-٢٦ بلا اختبارٍ واحدٍ يحمرّ. **ابنِ الطالبَ يدويّاً واترُكِ العمودَ NULL.**

## US1 — للكورسِ صفحة

```bash
curl -s http://localhost:8000/api/v1/marketplace/courses/{uuid} | jq
```

- يردُّ ٢٠٠ **بلا رأسِ مصادقة**
- `curriculum` عناوينُ ومُدَد — **صفرُ `uuid` لدرسٍ وصفرُ مسارِ وسائط**
- كورسٌ مسوّدة ⇒ ٤٠٤ **بنفسِ جسمِ** ٤٠٤ لـuuid مخترَع

على الشاشة: افتحْ `/courses` واضغطْ بطاقة. **العنوانُ الذي تصلُ إليه عنوانُ الكورسِ** — والضغطةُ واحدةٌ لا ثلاث (`SC-001`).

```bash
curl -s http://localhost:3000/courses/{uuid} | grep -c "المنهج"   # ≥1 ⇒ مُصيَّرٌ على الخادم (SC-008)
```

## US2 — المجموعات

اقرأْ `data.cohorts` من نفسِ النداء:

- الممتلئةُ `status: "full"` وبلا دعوةٍ للانضمام
- المؤرشَفةُ **غائبة**
- بلا سَعةٍ ⇒ `seats_left` **غائبٌ لا صفر**
- **ولا حقلَ واحدٌ عن الأعضاء** — لا اسمَ ولا عدد

## US3 — الطلبُ ودورتُه

```bash
# ١) الإرسال
POST /api/v1/private-session-requests  {course_uuid, starts_at}      → 201
# ٢) ولا شيءَ تحرّك
```

بعدَ الإرسالِ **مباشرةً**، عُدَّ ثلاثةَ أشياءَ وكلُّها صفر: حصصٌ جديدة، قيودُ رصيد، أرصدةٌ متحرّكة (`FR-017`).

```bash
# ٣) القبول
POST /api/v1/private-session-requests/{uuid}/accept                  → 200
```

وعُدَّ أربعةً وكلُّها **واحد** (`SC-006`): مجموعةٌ فرديّةٌ للطالبِ في هذا الكورس · حصّةٌ `individual` بمقعدٍ واحدٍ داخلَها · حجزُ مقعدٍ للطالب · إشعارٌ واحدٌ له.

ثمّ **اقبلْ طلباً ثانياً** وتحقّقْ أنّ المجموعةَ **لم تتكرّر** (`SC-006أ`) — وأنّ خيطَ المحادثةِ ما زالَ واحداً.

⚠️ **وعندَ القبولِ لا يُخصَمُ رصيد، وهذا صحيح.** الخصمُ يقعُ على تسليمِ الحصّةِ كما يقعُ لكلِّ حصّةٍ في المنتَج (`research.md` · قرار ٤). من يتوقّعُ قيداً هنا يقرأُ الصوابَ عطلاً.

### الحدودُ الأربعة

| ما تُجرّبُه | ما يجبُ أن يحدث |
|---|---|
| طلبٌ ثانٍ على نفسِ اللحظة | ٤٢٢ «مكرّر» |
| طلبٌ رابعٌ عندَ نفسِ المدرّس | ٤٢٢ «لديك ثلاثةٌ تنتظرُ الردّ» — ويُقبَلُ فورَ البتِّ في أحدِها |
| وقتٌ يبدأُ داخلَ الفترةِ وينتهي خارجَها | ٤٢٢ — **الفحصُ على المدّةِ لا على البداية** (`FR-016ب`) |
| قبولٌ بعدَ رفض | ٤٠٩ |

## الأفخاخُ الثلاثة — ولكلٍّ اختبارٌ يحمرُّ إن وقعنا فيه

فخٌّ مكتوبٌ في وثيقةٍ يُقرَأُ مرّةً ثمّ يُنسى. الثلاثةُ التالية لها اختبارات، وكلُّ واحدٍ منها **مصوغٌ ليسقطَ على الصيغةِ الخاطئة** لا ليمرَّ على الصحيحة — وهذا فرقٌ ليس لفظيّاً: الصيغةُ الساذجةُ من كلِّ اختبارٍ منها تمرُّ على بناءٍ لا حارسَ فيه إطلاقاً.

### ١ · `pending_slot` — والحالةُ الحاملةُ هي الثالثة

الفهرسُ الجزئيُّ (`WHERE status = 'pending'`) **موجودٌ في SQLite ومعدومٌ في MySQL**، فالصيغةُ الخاطئةُ لا تحمرُّ محلّيّاً أبداً: تمرُّ خضراءَ ثمّ تُسقِطُ الهجرةَ على الإنتاج. والعطلُ الأخطرُ ليس هذا، بل أن يُكتَبَ العمودُ ولا **يتحرّكَ** عندَ البتّ:

⚠️ **والصيغةُ المنفَّذةُ `pending_slot` لا `pending_key`** — نفسُ حارسِ `closed_slot` و`cohort_transfer_requests` حرفاً بحرف: صفرٌ ما دامَ الطلبُ قائماً، ومعرّفُ الصفِّ نفسِه بعدَ البتّ. الحارسُ واحدٌ والاختبارُ لا يتغيّر؛ ما يزولُ نسخةٌ ثانيةٌ مُسلسَلةٌ من عمودَينِ حاضرَينِ أصلاً، تتباعدُ عنهما أوّلَ تغييرٍ في صيغةِ الوقت.

```
١) طلبٌ على الأحد ١٠:٠٠                   → 201
٢) طلبٌ ثانٍ على نفسِ اللحظة               → 422
٣) ارفضِ الأوّلَ ثمّ اطلبْ نفسَ اللحظةِ    → 201   ← الحالةُ الحاملة
```

بلا الثالثةِ يمرُّ الاختبارُ على بناءٍ لا يُحرِّكُ `pending_slot` عن صفرِه إطلاقاً — فكلُّ موعدٍ رُفِضَ فيه طلبٌ يصيرُ محجوزاً على الطالبِ إلى الأبد، بلا خطأٍ في أيِّ سجلّ.

### ٢ · `$fillable` — يُقاسُ على الصفِّ المخزَّنِ لا على جسمِ الردّ

```php
$course->refresh();                                    // أو Course::find()
expect($course->private_session_minutes)->toBe(45);
```

توكيدٌ على جسمِ الردِّ **يمرُّ مهما كان**: الردُّ يُصدِّرُ ما أُرسِلَ لا ما خُزِّن، والإسنادُ الجماعيُّ يُسقِطُ المفتاحَ غيرَ القابلِ للتعبئةِ **بلا استثناءٍ ولا سجلّ**. ثلاثةُ أعمدةٍ على `student_profiles` شُحِنَت هكذا في ٠١٣ وكلُّ توكيداتِها كانت صحيحة.

### ٣ · المجموعةُ الفرديّةُ — تُفتَحُ عمداً ثمّ يُطلَبُ غيابُها

```php
$individual->update(['status' => 'open']);      // انزعِ الصدفةَ أوّلاً
// GET /api/v1/marketplace/courses/{uuid}
expect($cohortUuids)->not->toContain($individual->uuid);
```

المجموعةُ الفرديّةُ **مغلقةٌ منذُ إنشائها**، فغيابُها عن الحمولةِ اليومَ قد يكونُ لسببٍ لا علاقةَ له بكونِها فرديّة. اختبارٌ يتركُها مغلقةً يُصادِقُ على تصفيةٍ بالحالةِ وهو يظنُّ نفسَه قاسَ تصفيةً بالمالك — وثمنُ الخطأِ اسمُ طالبٍ في حمولةٍ عامّة.

## المسارُ الحرجُ الذي يمسُّه هذا العمل

`FR-019ب` يُدخِلُ تسجيلَ حصّةٍ خاصّةٍ في شجرةِ الكورس. شغّلْ:

```bash
php vendor/bin/pest tests/Feature/Learning
```

وتحقّقْ أنّ **نسبةَ إنجازِ طالبٍ لم تتغيّرْ** بعدَ نشرِ التسجيل. `progressEligible()` تُسقِطُ أيَّ درسٍ يحملُ `class_session_id`، فالخاصيّةُ قائمةٌ بالبناء — لكنّها **تبقى صدفةً حتّى يُثبِتَها اختبار**. عنصرٌ يدخلُ المقامَ ولا يُكمِلُه أحدٌ يُبقي كلَّ طالبٍ تحتَ ١٠٠٪ **إلى الأبد**، فلا يُطلَقُ `CourseCompleted` ولا تصدرُ شهادةٌ واحدة.

## التزامن — لا يُقاسُ بمتصفّحَين

`SC-007` يُقاسُ بردِّ نداءٍ **في منتصفِ النافذة**: تُنادى نقطةُ الاتّخاذِ بينَ القراءةِ والكتابةِ فيصيرُ «العاملُ الآخرُ» حدثاً داخلَ النافذةِ نفسِها — بلا خيوطٍ وبلا `sleep`. اختبارٌ متسلسلٌ ساذجٌ («اقبلْ مرّتَين») **يمرُّ على بناءٍ لا مطالبةَ فيه إطلاقاً**، لأنّ النداءَ الثاني يرتدُّ من سطرٍ أعلى. الاصطلاحُ قائمٌ في هذا المستودعِ ومُستعمَلٌ في المقعدِ والالتقاطِ وابتلاعِ التسجيل.

## Playwright

```bash
cd frontend && npx playwright test
```

سبقٌ لازم: `PHP_CLI_SERVER_WORKERS=8`. البناءُ يُصيِّرُ سلفاً في عمّالٍ متوازين، وخادمُ PHP بخيطٍ واحدٍ يُجيبُ الأوّلَ ويرفضُ البقيّة — فيسقطُ البناءُ قبلَ اختبارٍ واحد. وأيُّ مواصفةٍ تختبرُ **زائراً** تحتاجُ `test.use({ storageState: { cookies: [], origins: [] } })` صراحةً، وإلّا اختبرت مستخدماً مسجَّلاً وهي تظنُّ نفسَها ضيفاً — وصفحةُ الكورسِ العامّةُ هي بالضبطِ ما يجبُ أن يُقاسَ ضيفاً.
