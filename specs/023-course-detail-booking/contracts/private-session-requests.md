# عقد — طلبُ الحصّةِ الخاصّة

كلُّها خلفَ `auth:sanctum` وداخلَ مجموعةِ `api` (فيها `EnsureCurrentWorkspace`، وهي ما يدفعُ معرّفَ الفريقِ إلى spatie — ومسارٌ يُعرَّفُ خارجَها يفقدُ كلَّ صلاحيّاتِه بلا أن يبدوَ كذلك).

## `POST /api/v1/private-session-requests` — الطالب

```jsonc
{ "course_uuid": "…", "starts_at": "2026-09-12T13:00:00Z" }
```

`starts_at` **لحظةٌ مطلقةٌ بمنطقةٍ زمنيّة**. نصُّ وقتٍ محلّيٍّ بلا منطقةٍ يُنتِجُ حصّةً في ساعةٍ لم يقصدْها أحد.

المدّةُ **لا تُرسَل** — تُقرَأُ من الكورس (`FR-016أ`). حقلٌ يُرسِلُه العميلُ حقلٌ يستطيعُ تزويرَه.

| الردّ | متى |
|---|---|
| `201` | سُجِّل |
| `403` | غيرُ مسجَّلٍ في الكورس (`FR-015أ`) · أو ممنوعٌ من الحجزِ لسببٍ ماليّ (`FR-025`) |
| `422` | الوقتُ خارجَ فترةِ توفّرٍ معلَنة (بمدّتِه لا ببدايتِه) · طلبٌ مكرّرٌ على نفسِ اللحظة · تجاوزُ حدِّ الطلباتِ القائمة |

كلُّ رفضٍ يحملُ `code` تقرؤه الواجهةُ وجملةً عربيّةً يقرؤها الإنسان.

## `GET /api/v1/private-session-requests` — الطرفان

الطالبُ يرى طلباتِه عبرَ **كلِّ** مدرّسيه؛ والمدرّسُ الواردَ إليه في مساحتِه وحدَها. الاستعلامُ يُصفّى **صراحةً** بالمالك أو بـ`teacher_profile_id`، لا يُترَكُ لنطاقٍ عامّ.

⚠️ **والطالبُ عضوٌ في لا مساحةَ إطلاقاً**، فـ`WorkspaceContext::id()` تُجيبُ `null` له و`WorkspaceScope` تُضيفُ **صفرَ شرط**. أي أنّ الصفَّ الصريحَ هو الحارسُ الوحيد؛ ورَبْطُ نموذجٍ ضمنيٍّ بالمسارِ هنا يفتحُ طلبَ أيِّ شخص.

## `POST /api/v1/private-session-requests/{uuid}/accept` — المدرّس

`SESSIONS_MANAGE` + `PrivateSessionRequestPolicy::decide`. أثرُه واحدٌ لا يتجزّأ (`FR-020`): مجموعةٌ فرديّةٌ إن لم توجدْ ← حصّةٌ `individual` بمقعدٍ واحد ← حجزُ المقعد ← حدثُ `PrivateSessionAccepted`.

| الردّ | متى |
|---|---|
| `200` | قُبِل |
| `409` | بُتَّ فيه سلفاً (`UPDATE … WHERE status = 'pending'` لم يُطابِقْ صفّاً) |
| `422` | تعارضٌ مع حصّةٍ أخرى (`FR-021`) · رصيدٌ لم يعُدْ يكفي أرضيّةَ الحجز |

## `POST /api/v1/private-session-requests/{uuid}/reject` — المدرّس

```jsonc
{ "reason": "…" }
```

## `DELETE /api/v1/private-session-requests/{uuid}` — الطالب

سحبٌ ما دامَ `pending` (`FR-024`). `409` بعدَ البتّ.

---

## أربعةُ أنواعِ إشعارٍ

`private_session_requested` → المدرّس · `…_accepted` · `…_rejected` · `…_expired` → الطالب.

بالنوعِ لا بالقناة، ولكلٍّ **قالبٌ مبذورٌ وهجرةُ ردمٍ في نفسِ التغيير**: إشعارٌ بلا قالبٍ يُسقَطُ **بصمت** — لا خطأَ ولا سطرَ في السجلّ — والاختباراتُ خضراءُ لأنّ `tests/Pest.php` تبذرُ القوالبَ قبلَ كلِّ حالة، فتقعُ كلُّ توكيداتِها على جدولٍ قد لا يملكُه الإنتاج. ولا واحدٌ منها يستهدفُ وليَّ الأمر — حوارٌ بينَ الطالبِ ومدرّسِه.
