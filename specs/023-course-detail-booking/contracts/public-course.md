# عقد — القراءةُ العامّةُ للكورس

## `GET /api/v1/marketplace/courses/{uuid}`

بلا مصادقة. `throttle:public` — **المحدِّدُ مُسمّىً، ولا `throttle:60,1` سطريّاً**: الحارسُ يُفهرِسُ الضيوفَ بـ`domain|ip` بلا المسارِ في البصمة، فكلُّ حدٍّ سطريٍّ يتقاسمُ عدّاداً واحداً ويفوزُ أشدُّها — وتصفُّحُ المتجرِ يمنعُ الزائرَ من تسجيلِ الدخول.

**المفتاحُ `uuid` لا `slug`**: `courses.slug` فريدٌ لكلِّ (`workspace_id`, `slug`) — أي داخلَ المساحةِ وحدَها — ومسارٌ عامٌّ بلا مساحةٍ لا يستطيعُ التفريقَ بينَ «الرياضيات ٣» عندَ مدرّسَين.

### ٢٠٠

```jsonc
{
  "data": {
    "uuid": "…", "slug": "calculus-basics",
    "title": "أساسيّات التفاضل",
    "description": "…",            // Markdown يُصيَّرُ عندَ العرض، لا HTML مخزَّن
    "cover_url": "…|null",
    "subject":     { "slug": "math",      "name_ar": "الرياضيات", "icon": "calculator" },
    "grade_level": { "slug": "secondary", "name_ar": "الثانوية" },
    "teacher": { "uuid": "…", "slug": "…", "name": "…", "avatar_url": "…",
                 "trust_score": 91, "trust_band": "high" },
    "lessons_count": 24,
    "duration_seconds": 43200,
    "average_rating": 4.8,
    "enrolled_count": 213,
    "price_minor": 24900, "currency": "QAR",
    "curriculum": [
      { "title": "المشتقّة", "chapters": [
          { "title": "التعريف", "items": [
              { "title": "تعريف المشتقّة", "kind": "video", "duration_seconds": 720 }
          ]}
      ]}
    ],
    "cohorts": [
      { "uuid": "…", "name": "مجموعة السبت", "description": "…|null",
        "status": "open|full|closed",
        "schedule": ["السبت 16:00", "الثلاثاء 16:00"],
        "seats_left": 3 }
    ]
  }
}
```

- **لا `id` تسلسليّ** في أيِّ موضع.
- **لا `uuid` لعنصرِ منهج** ولا مسارَ وسائط (`FR-005`).
- ⚠️ **المنهجُ ثلاثةُ مستوياتٍ لا اثنان** — تصحيحٌ ثانٍ. الرسمُ الأوّلُ وضعَ الدروسَ تحتَ القسمِ مباشرةً، و`FR-005` يقولُ «الأقسامَ **والفصولَ** وعناوينَ الدروس»، و`lessons.chapter_id` **غيرُ قابلٍ لـNULL** — فكلُّ درسٍ في فصل، وتسطيحُ الفصلِ يعرضُ للزائرِ شكلاً لم يبنِه المدرّس.
- ⚠️ **`schedule` قائمةُ نصوصٍ عربيّةٍ قصيرة، لا قائمةُ كائنات** — تصحيحٌ ثالث. `CohortScheduleDirectory` يُجيبُ «متى تجتمعُ هذه المجموعة» منذ ٠٢١ بنفسِ الصيغةِ التي يعرضُها منتقي المجموعاتِ للطالب. شكلٌ ثانٍ هنا اشتقاقٌ ثانٍ لحقيقةٍ واحدة، وأوّلُ حالةِ حصّةٍ تُضافُ يجعلُ المتجرَ يُعلِنُ موعداً لا يعرضُه المنتقي.
- ⚠️ **السعرُ حاضرٌ هنا وغائبٌ عن البطاقة** — تصحيحٌ قِيسَ أثناءَ التنفيذ. `PublicCourseCardResource` مكتوبٌ فيها أنّ ٠٠٦ · `FR-021هـ` أخرجَ السعرَ من أسطحِ التصفّحِ وأبقاه على «صفحةِ الوحدةِ القابلةِ للشراء» — وتلك الصفحةُ لم تكن موجودة، فنصفُ القاعدةِ وحدَه كان مُنفَّذاً. و`FR-028` («لا مبلغ») عن **الرصيد**: سعرُ الرصيدِ يُحَلُّ منه معدَّلُ تسويةِ المدرّس، وثمنُ الكورسِ لا تربطُه بمعدَّلٍ معادلة. ولهذا `hourly_rate` في `FORBIDDEN` و`price_minor` ليس فيها.
- **لا مبلغَ يخصُّ الرصيدَ أو التسوية** في أيِّ حقلٍ (`FR-028`).
- `seats_left` غائبٌ حين لا سَعةَ للمجموعة — **غيابٌ لا صفر** (`FR-012`): «غيرُ محدود» ليس رقماً، والصفرُ يُقرأُ «ممتلئة».
- المجموعةُ الفرديّةُ **غائبةٌ تماماً** (`FR-019هـ`) — تُصفّى بـ`individual_for_user_id IS NULL` لا بالحالة.

### ٤٠٤

كورسٌ غيرُ منشور · مدرّسٌ غيرُ معتمَد · مساحةٌ منسحبةٌ من المتجر · uuid لا وجودَ له — **جسمُ الردِّ نفسُه في الأربع** (`FR-007`). فرقٌ واحدٌ بينَ حالتَينِ يجعلُ المنفذَ عرّافاً يُخبِرُ بما لا يُنشَر.

### ما يحرسُه اختبار

| | |
|---|---|
| `PublicExposureTest` | كلُّ حقلٍ في الحمولةِ مُدرَجٌ في `COURSE_DETAIL`/`COHORT` — والبناءُ يسقطُ عندَ حقلٍ غيرِ مُدرَج |
| `QueryBudgetTest` | سقفٌ ثابتٌ **مع تأكيدِ حضورِ الحقول**: إسقاطُ تحميلٍ مسبقٍ مع `whenLoaded` يُنتِجُ صفحةً أرخصَ بحقلٍ غائب، فتُقرَأُ الخسارةُ ربحاً |
| اختبارُ التسريب | يقارِنُ على `JSON_UNESCAPED_UNICODE` — `getContent()` يهربُ غيرَ ASCII، فإبرةٌ عربيّةٌ لا تُطابِقُ شيئاً مهما حملت الحمولة، والملفُّ كلُّه يمرُّ على ردٍّ سرّبَ كلَّ شيء |
