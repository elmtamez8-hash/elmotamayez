# Quickstart: التجارة والنمو (Phase 1)

**Spec**: [spec.md](./spec.md) · **Plan**: [plan.md](./plan.md)

**النسخةُ الثانية (2026-08-29)** — بعدَ مراجعةِ الوكلاءِ الخمسة. الحالاتُ المُعلَّمةُ بـ⚠️
كُتِبَتْ لعطلٍ **كُشِفَ في المراجعةِ ولا حارسَ له في الشجرةِ اليوم**.

**كلُّ موجةٍ تُدمَجُ خضراءَ وحدَها.** دفعةٌ واحدةٌ في آخرِ ٤٨ متطلَّباً تُراجَعُ بلا مراجِع.

---

## البوّاباتُ الأربعُ (‏NFR-008 · SC-017)

```bash
cd backend  && php vendor/bin/pest
cd backend  && ./vendor/bin/pint --test
cd backend  && ./vendor/bin/phpstan analyse       # L8 · بلا خطِّ أساسٍ جديدٍ وبلا @phpstan-ignore
cd frontend && npx tsc --noEmit && npm test
```

⚠️ `php artisan migrate` وحدَه — **لا `migrate:fresh`**، والإذنُ يُطلَبُ قبلَ إتلافِ قاعدةٍ
فيها بياناتُ جلساتٍ سابقة.

⚠️ **وبعدَ أوّلِ هجرةٍ في `Store`**: `phpstan` يجبُ أن يظلَّ صفراً — خطأُ «خاصّيّةٌ غيرُ
معرَّفة» على نماذجِ المتجرِ سببُه صفٌّ ناقصٌ في `phpstan.neon` لا نوعٌ خاطئ.

**بيدٍ**:

```bash
curl -s http://127.0.0.1:3000/sitemap.xml | head -30
curl -s http://127.0.0.1:3000/robots.txt
curl -s http://127.0.0.1:3000/blog/<slug> | grep -o 'application/ld+json'
```

ثمّ افتحِ المقالَ في **نافذةٍ خاصّة** (بلا جلسة): يُقرَأُ كاملاً. ومسوّدةً برابطِها المباشرِ
في النافذةِ نفسِها: تُرفَض.

⚠️ **و`npx playwright test` يحتاجُ `PHP_CLI_SERVER_WORKERS=8 php artisan serve`**: التهيئةُ
تبني للإنتاجِ وNext يُصيِّرُ صفحاتٍ مسبقاً بجلبٍ من الـAPI بعمّالٍ متوازين، وخادمُ PHP المدمجُ
بخيطٍ واحدٍ يردُّ الأوّلَ ويرفضُ الباقي ⇒ فشلُ **البناءِ** قبلَ أوّلِ اختبار.
