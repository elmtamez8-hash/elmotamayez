# API Contracts — التوسّع والتطبيق (spec 012)

كلُّ ما هنا خلفَ `auth:sanctum` وتحت `/api/v1`. لا مسارَ عامّاً واحداً في هذه المرحلة.

**القواعدُ السارية، مرّةً واحدةً بدل تكرارِها تحت كلِّ مسار**:

- **الكيانُ يُعنوَن بـuuid دائماً** — جلسة، غرفة، فكرة، مدرّس. **والخياراتُ داخلَ سؤالٍ
  استثناءٌ مقصود**: `AssessmentFieldAllowlist::sitOptionFields()` هو `['id', 'content']`
  و`AssessmentExposureTest` يؤكّد ذلك الشكلَ بعينِه. الخيارُ ليس كياناً يُعنوَن من الخارج —
  هو صفٌّ داخل سؤالٍ داخل محاولةٍ يملكها القارئُ سلفاً، وuuidٌ له عقدٌ إضافيٌّ بلا قارئ.
  (النسخةُ الأولى من هذا الملفِّ منعت المُعرِّفَ التسلسليَّ في سطرٍ وأرسلته في ثلاثة.)
- **ولا ربطَ ضمنيّاً للنموذجِ على أيِّ مسارٍ يصل إليه طالب.** `WorkspaceScope` عديمُ الأثرِ
  لمن سياقُه `null` — وهو كلُّ طالب. الـuuid يُحَلّ **داخلَ الـAction بعد فحصِ الأهلية**
  (سابقةُ `RedeemReward`)، وينطبق على `concept` كذلك (`BuildSelfExam::conceptId()`).
- **كلُّ استجابةٍ تمرّ بـAPI Resource.** والحمولاتُ الستُّ الجديدةُ تُسجَّل في
  `AssessmentFieldAllowlist` وتُمشى في `AssessmentExposureTest` — قائمتُه **مصونةٌ باليدِ
  عمداً**، وتعليقُه يقول: «حمولةٌ غائبةٌ عنها حمولةٌ لا يمشي عليها شيء».
- **المُحدِّداتُ مسمّاةٌ دائماً**؛ لا `throttle:5,1` سطريّاً — `ThrottleRequests` يفهرس الضيوفَ
  بـ`domain|ip` بلا مسارٍ في التجزئة، فكلُّ حدٍّ سطريٍّ يتقاسم عدّاداً واحداً.
- **المفتاحُ يُقرأ في الـAction بمعرّفِ مساحةِ عملٍ صريح** — من معامل `teacher` أو من
  `study_rooms.workspace_id`، **أبداً من `WorkspaceContext`**: هو `null` لكلِّ طالب،
  و`(int) null === 0` يخاطب صفَّ المنصّةِ المزروعِ مطفأً ⇒ `403` للجميع.
  مفتاحٌ مطفأٌ ⇒ **403** `{ code: "feature_off" }`.
- **الخطأُ العمليُّ `DomainException` ⇒ 422 بجملةٍ عربيّة.** ⚠️ و`DomainException` يرث
  `LogicException` لا `RuntimeException` — متحكّمٌ يلتقط الثانيَ وحدَه يمرّره إلى 500.
- **ولا نصَّ خامٍ للمستخدم**: 422 عبر `fieldErrors()`، وما عداه عبر `userMessage()`. الشيفراتُ
  الثلاثُ الجديدةُ (`feature_off` · `room_closed` · `not_eligible`) لها جملٌ في
  `src/lib/errors.ts`.

## US1 — المسار التكيّفي

### `POST /practice/adaptive` — ابدأ جلسة

`throttle:practice` · مفتاح `adaptive_practice` بمساحةِ عملِ `teacher`

```jsonc
{ "concept": "9f2c…", "teacher": "3ab1…" }
```

```jsonc
// 201
{
  "data": {
    "uuid": "7d4e…",
    "concept": { "uuid": "9f2c…", "name": "المشتقّات" },
    "status": "running",
    "difficulty": "easy",              // الصعوبةُ الابتدائيةُ مُعلَنة (FR-001)
    "ceiling_difficulty": "medium",    // ⚠️ أعلى متاحٍ في هذه الفكرة
    "served_count": 0,
    "max_questions": 20,
    "mastery_after": 3,                // العتبةُ الحيّةُ، معلَنةٌ لا مخفيّة (FR-003)
    "question": {
      "question_id": 512,              // عنوانُ الإجابة — انظر أدناه
      "order": 1,
      "content": "…",
      "difficulty": "easy",
      "options": [{ "id": 41, "content": "…" }]
    }
  }
}
```

**⚠️ `ceiling_difficulty` مُعلَنٌ لأنّ الإتقانَ يُقاس عندَه.** فكرةٌ ليس فيها سؤالٌ `hard`
سقفُها `medium`، والطالبُ يتقنها هناك. لو كان السقفُ `hard` حرفيّاً لَما بلغَت الإتقانَ
**أبداً** — والشاشةُ كانت ستطلب من الطالبِ ما لا يستطيع بلوغَه بأيِّ فعل.

**⚠️ ولا حقلَ `is_correct` ولا `correct_option_ids` في أيِّ سؤالٍ يُقدَّم.** الصوابُ يصل في
ردِّ الإجابةِ وحدَه. وهذا التوكيدُ يُختبَر بـ**سنتينلٍ ASCII** أو بـ`JSON_UNESCAPED_UNICODE`:
`getContent()` يهرّب غيرَ الـASCII، فتوكيدٌ عربيٌّ بالنفي **صادقٌ خاوياً مهما حملت الحمولة** —
وهو ما يوجَد `AssessmentExposureTest::bodyText()` لمنعِه.

**422** حين لا فكرةَ في متناولِ الطالب، أو لا سؤالَ في الفكرةِ إطلاقاً.
**409** حين له جلسةٌ جاريةٌ على الفكرةِ نفسِها — يُعاد uuidُها بدل فتحِ ثانية.

### `POST /practice/adaptive/{uuid}/answer` — أجب، وخذ التالي

`throttle:adaptive-step` (٦٠/دقيقة بمفتاح المستخدم)

```jsonc
{ "question_id": 512, "option_ids": [41] }
```

**⚠️ العنوانُ `question_id`، لا `order`.** `attempt_items` فريدٌ على
`(attempt_id, question_id)` وحدَه؛ و`order` يُسنَد تصاعديّاً هنا (`max(order) + 1`، قراءةٌ ثمّ
كتابة)، فصفّانِ بالرقمِ نفسِه يجعلان `{"order": 3}` عنواناً مبهماً: تُصحَّح إجابةُ الطالبِ على
سؤالٍ آخر، والفهرسُ الفريدُ لا يراه لأنّ السؤالَين مختلفان. والمسارُ القائم
(`AttemptController::submit`) يعنون بـ`question_id` سلفاً.

```jsonc
// 200 — الجلسةُ مستمرّة
{
  "data": {
    "result": {
      "is_correct": false,
      "correct_option_ids": [42],
      "explanation": "…"               // فوريّاً — هذا هو التمرين
    },
    "session": {
      "status": "running",
      "difficulty": "easy",            // نزلت من medium بعد الخطأ (FR-002)
      "difficulty_changed": true,
      "difficulty_note": "نزلنا لسؤالٍ أسهل في الفكرة نفسها.",
      "served_count": 2,
      "correct_streak": 0
    },
    "question": { "question_id": 913, "order": 2, "content": "…", "difficulty": "easy", "options": [] }
  }
}
```

```jsonc
// 200 — الفكرةُ أُتقنت
{
  "data": {
    "result": { "is_correct": true, "correct_option_ids": [88], "explanation": "…" },
    "session": { "status": "mastered", "mastered_at": "2026-08-29T18:04:00Z", "score": 14 },
    "question": null,
    "suggestion": { "concept": { "uuid": "ab21…", "name": "التكامل" } }
  }
}
```

**`difficulty_note` هي FR-004 حرفيّاً**: حين تنفد الأسئلةُ عند صعوبةٍ يمشي المسارُ إلى أقربِ
متاحةٍ في الفكرةِ نفسِها **ويقول ذلك**. حقلٌ صامتٌ يعني طالباً يرى صعوبةً لم يطلبْها.

**⚠️ و`suggestion` تُبنى من خريطةِ الأفكارِ المحمَّلةِ سلفاً، لا باستعلامِ مجمَّعٍ جديدٍ داخلَ
أسخنِ مسارِ كتابةٍ في المرحلة.**

**409** على إجابةٍ ثانيةٍ لـ`question_id` نفسِه. ⚠️ **وهو مطالبةٌ ذرّيّةٌ في الـAction
وفهرسٌ خلفَها، لا فهرسٌ وحدَه**: تعليقُ هجرةِ `unique(attempt_id, question_id)` يقول بنصِّه إنّ
«القيدَ وحدَه يحوّل التسليمَ المزدوجَ إلى **٥٠٠** لا إلى رفضٍ نظيف». الرفضُ النظيفُ يحتاج
الاثنَين.
**404** حين لا تخصّ الجلسةُ صاحبَ الطلب — لا 403: وجودُ جلسةٍ لغيرِه ليس خبراً يُعطى.

### `POST /practice/adaptive/{uuid}/end`

`throttle:adaptive-step`. `200` بملخّصِ الجلسة، وعودةٌ مبكّرةٌ نظيفةٌ على حالةٍ طرفيّة.

**⚠️ ويختم المحاولةَ بنفسِه** — `submitted_at` و`finalized_at` و`score` من مجموعِ ما كُتب
سؤالاً سؤالاً — **ولا يمرّ بـ`GradeAttempt`** (يكتب صفَّ إجابةٍ لكلِّ عنصرٍ فيصطدم)، **ولا
يُطلق `AttemptFinalized`** (مستمعُه في الإشعاراتِ يُطلق لمحاولاتِ التمرينِ عمداً، فكانت كلُّ
جلسةٍ ستُنتج إشعارَ «نتيجةُ اختبار»). الحدثُ الوحيدُ `ConceptMastered`، وعند الإتقانِ وحدَه.

### `GET /practice/adaptive/concepts`

`throttle:practice`.

```jsonc
{
  "data": [
    { "uuid": "9f2c…", "name": "المشتقّات", "teacher": { "uuid": "3ab1…", "name": "أ. سارة" },
      "question_count": 24, "ceiling_difficulty": "hard", "mastered_at": null }
  ]
}
```

**⚠️ استعلامٌ مُجمَّعٌ واحد، لا واحدٌ لكلِّ فكرة.** `question_count` و`ceiling_difficulty`
يأتيان من `GROUP BY concept_id` فوقَ المجمَّعِ نفسِه. الشكلُ البديهيُّ — حلقةٌ تسأل المجمَّعَ
لكلِّ فكرةٍ — هو N+1 غيرُ محدود، وكلُّ دورةٍ تُعيد بناءَ قائمةِ المطروحِ كاملةً.

**⚠️ ويحمل مُحدِّداً** رغم أنّه قراءة: هو أثقلُ قراءةٍ في المرحلة.

**⚠️ والقائمةُ مشتقّةٌ من `PracticePool` نفسِه** الذي يسحب منه المسار. قائمةٌ تُجمَّع بجانبِه
تعرض فكرةً يردّ عليها المسارُ ٤٢٢، وتُخفي فكرةً كان سيقبلها — عطلُ `ListLeaderboardScopes`
في 009.

**والمفتاحُ يُرشِّح ولا يرفض**: لا معاملَ `teacher` هنا والمجمَّعُ يمتدّ عبر كلَّ من يدرس
عندهم الطالب، فـ«هل المفتاحُ مشتعل» له N جواباً. تُقرأ خريطةُ المفاتيحِ لكلِّ مساحةٍ
(`Flags::map()`، استعلامٌ واحدٌ لكلِّ مساحة) وتُرشَّح النتيجة. **قائمةٌ فارغةٌ حالةٌ، لا رفض** —
`403` هنا يعني «الميزةُ معطَّلةٌ» عن شاشةٍ ليست خطأً.

## US2 — الإشعارُ الفوريّ

### `POST /notifications/push-subscriptions`

`throttle:gamification-write`

```jsonc
{
  "endpoint": "https://fcm.googleapis.com/fcm/send/…",
  "keys": { "p256dh": "BN…", "auth": "kT…" },
  "user_agent": "…"
}
```

**`204` دائماً** — أنشأ أم حدّث. ⚠️ **والتوحيدُ ليس تجميلاً**: `201` مقابل `200` **عرّافٌ**
يخبر السائلَ أنّ ذلك العنوانَ مسجَّلٌ سلفاً، وهو ما بُني الردُّ الموحَّدُ في `DELETE` لمنعِه.
قاعدتانِ متضادّتانِ على عمودٍ واحد.

**والكتابةُ `upsert()` على `(user_id, endpoint_hash)`**، لا `updateOrCreate` — تلك
`firstOrNew` + `save`: لسانانِ يعيدانِ التسجيل (سلوكُ عاملِ الخدمةِ المعتاد) يصطدمانِ على
الفهرسِ الفريدِ فيكون ٥٠٠ على المسارِ السعيدِ للميزة.

**والتفرّدُ مزدوجٌ لا عالميّ**: وليٌّ وطفلُه يتشاركانِ هاتفاً — فبعالميٍّ يسرق آخرُ من يشترك
صفَّ الآخرِ ويتوقّف عن تلقّي **كلِّ شيء** بما فيه `security_alert` الإلزاميّ، بلا خطأٍ وبلا
سجلّ.

**⚠️ وأوّلُ اشتراكٍ يكتب تفضيلاتِ الدفعِ لفئاتِ `Sessions` و`Balance` و`Account`** — مقروءةً
من `NotificationCategory` القائم. بدونها لا يصل أحداً شيءٌ أبداً: `Push` **خارجَ**
`defaultChannels()` عمداً، و`PreferenceResolver` يستبدل الافتراضاتِ بالمخزَّنِ لا يُرشِّحُها.

**ولا uuid يُرَدّ.** الاشتراكُ لا يُعنوَن من الخارج: الإلغاءُ يرسل `endpoint`، والحذفُ الآخرُ
من `410 Gone`. مسارٌ يقبل uuidَ اشتراكٍ هو سؤالُ «أيُّ صفّ؟» مطروحاً على العميل.

### `DELETE /notifications/push-subscriptions`

```jsonc
{ "endpoint": "https://fcm.googleapis.com/fcm/send/…" }
```

`204` — للموجودِ ولغيرِ الموجود. مقيَّدٌ بـ`user_id` المصادَقِ عليه.

### الحمولةُ المدفوعة

**عنوانٌ قصيرٌ ورابطٌ فقط، لا نصُّ الرسالة.** لا سحبَ للتصريحِ في بروتوكولِ الدفعِ إلّا
بـ`410`، والجهازُ قد يكون مشتركاً — فرسالةُ `security_alert` أو تقريرُ غيابِ طفلٍ على شاشةِ
قفلٍ يقرؤها من بجانبِه.

### ما لا يُضاف

**لا مسارَ تفضيلاتٍ جديد**: `notification_preferences` يحمل القناةَ منذ 003. وFR-035 يتحقّق
بلا سطر: `canReach()` تُرجع `false` بلا اشتراك، والقناةُ تُسجَّل **متخطّاةً لا فاشلة**.

## US3 — غرف المذاكرة

### `POST /study-rooms` — أنشئ

`throttle:study-room-write` · مفتاح `study_rooms` بمساحةِ عملِ `teacher`

```jsonc
{
  "teacher": "3ab1…",
  "concept": "9f2c…",          // اختياريّ — null يعني الفكرةَ الأوسع
  "difficulty": "medium",      // اختياريّ — null يعني مختلطة
  "question_count": 10,        // ١–٣٠
  "max_participants": 12,      // ١–٣٠
  "duration_minutes": 15,
  "starts_in_minutes": 2
}
```

> `concept` و`difficulty` اختياريّانِ بينما `spec.md` FR-013 يذكرهما ضمنَ ما «يحدّده» المنشئ.
> الاختياريّةُ توسيعٌ لا تضييق: من حدّدهما حصل على ما وصفَته المواصفة، ومن تركهما حصل على
> ورقةٍ أوسعَ من مجمَّعِه هو نفسِه. **يُذكَر هنا لأنّه فرقٌ عن نصِّ المواصفة.**

```jsonc
// 201
{
  "data": {
    "uuid": "c81f…",
    "invite_url": "/study-rooms/c81f…",
    "state": "pending",
    "starts_at": "…", "ends_at": "…",
    "requested_count": 10,
    "delivered_count": 6,        // ⚠️ النقصُ جوابٌ لا فشل
    "max_participants": 12,
    "host": { "uuid": "…", "name": "خالد" }
  }
}
```

**⚠️ النقصُ يبني الورقةَ ويُبلِغ، ولا يردّ ٤٢٢.** النسخةُ الأولى ردّت ٤٢٢ واستشهدت بـFR-023 —
وهو يقول العكسَ بنصِّه: «نقصُ الأسئلةِ المتاحةِ **يجب** أن يُنتج اختباراً **بالمتاح** مع إبلاغِ
الطالب»، و`BuildSelfExam.php:86` يكتب فوقَه «SHORT IS AN ANSWER, NOT A FAILURE». الرفضُ
**فقط** حين يكون المتاحُ صفراً — وهو ما يفعله ذلك الصفُّ في السطرِ ٨٤.

**و`max_participants` سقفٌ يُفرَض في الـAction**: الدعوةُ uuid قابلٌ للتحويل وكلُّ زميلٍ
مؤهَّلٍ ينضمّ؛ بلا سقفٍ يكون البثُّ N صفّاً لـN مشتركاً لكلِّ إجابةٍ من N×M إجابة.

**والدعوةُ مفتوحةٌ لكلِّ مؤهَّلٍ يحملها** — قرارٌ صريح: لا قائمةَ مدعوّينَ ولا رمزَ ثانٍ.
الحدُّ هو الأهليّةُ والسقف.

### `GET /study-rooms` — غرفي

`throttle:study-room-write`. غرفُ القارئ: ما استضافه وما انضمّ إليه، أحدثُ أوّلاً، مرقَّمة.

```jsonc
{ "data": [ { "uuid": "c81f…", "state": "closed", "score": 7,
              "answered": 10, "question_count": 10, "ends_at": "…" } ] }
```

**⚠️ يُقرأ من `study_room_participants` عبر `index(user_id, joined_at)`** — الطالبُ ليس عضواً
في أيِّ مساحةِ عمل، فلا فهرسَ على `study_rooms` يخدمه، والفهرسُ المركّبُ الآخرُ يُقرأ من
عمودِه الأوّلِ فقط: بدونه مسحٌ كاملٌ لكلِّ فتحةِ صفحة.

**والمفتاحُ يُرشِّح ولا يرفض** — كما في قائمةِ الأفكار.

### `POST /study-rooms/{uuid}/join`

`throttle:study-room-write`

`200` بحالةِ المشارك.

**⚠️ شرطُ الأهليّة: مجمَّعُ **المنضمِّ نفسِه** يحتوي **كلَّ** سؤالٍ مجمَّدٍ في الغرفة** —
`$pool->questionsFor($ws, $joiner)->whereIn('id', $frozenIds)->count() === count($frozenIds)`.
النسخةُ الأولى اكتفت بـ«تسجيلٌ نشِطٌ في مساحةِ العمل»، وفيه عطلانِ:

1. `withheldQuestionIds()` **لكلِّ طالبٍ على حدة**. مضيفٌ سبق أن قدّم امتحاناً منشوراً يجمّد
   أسئلتَه مشروعاً، وكلُّ منضمٍّ لم يقدّمْه يجيب عنها **ويُعطى مفتاحَ الإجابةِ والشرحَ فوراً**:
   ورقةُ الأسبوعِ القادمِ بأجوبتِها، وهو نصُّ ما يوجَد `PracticePool` لمنعِه.
2. `questionsFor()` مقيَّدٌ **بالكورس** لا بمساحةِ العمل. فطالبُ «العربيّ» ينضمّ إلى غرفةٍ من
   بنكِ «الفيزياء». و`EnrollmentDirectory` سجّل هذا سلفاً: «لم يعُدْ كافياً وحدَه».

و FR-017 يقول «من لا يحقّ له الوصولُ إلى **أسئلتها**»، لا «إلى مساحتها».

**403** `{ code: "not_eligible" }` — بلا تسمِيةِ امتحانٍ ولا كورس.
**409** `{ code: "room_closed" }` بعد `ends_at` (FR-016) — مشتقٌّ من الساعة.
**409** `{ code: "room_full" }` عند بلوغِ السقف.

**والانضمامُ يُطالِب صفَّ المشاركةِ أوّلاً**، ثمّ يُنشئ المحاولةَ وعناصرَها، والكلُّ في معاملةٍ
واحدة — الترتيبُ المعكوسُ يترك على الخاسرِ محاولةً يتيمةً وN عنصراً بلا مشاركٍ ولا كنس.

### `GET /study-rooms/{uuid}`

`throttle:adaptive-step`. حالةُ الغرفةِ، واللوحةُ، و**موضعُ المشاركِ المحفوظ** — FR-015
و SC-007: الاستئنافُ قراءةُ صفٍّ لا استعادةُ ذاكرةِ متصفّح.

**⚠️ ولا `correct_option_ids` ولا شرحٌ لسؤالٍ لم يُجَبْ بعد.** اللقطةُ المخزَّنةُ تحمل
المجموعةَ الصحيحة (`QuestionSnapshot::of()`)، والقاعدةُ كانت مكتوبةً على المسارِ التكيّفيِّ
وحدَه. تُسجَّل هذه الحمولةُ في `AssessmentFieldAllowlist::forbiddenDuringAttempt()`.

### `POST /study-rooms/{uuid}/answer`

`throttle:adaptive-step`. يصحّح، يحدّث الصفَّ، **ويبثّ اللوحة**.

**409** على إجابةٍ ثانيةٍ لـ`question_id` نفسِه — مطالبةٌ وفهرسٌ، لا فهرسٌ وحدَه.

**⚠️ وهو كاتبُ `StudyRoomFinished`**: حين تكون هذه هي الإجابةَ التي أكملت المجموعة، يختم
`finished_at` ويُطلق الحدثَ ويختم المحاولة. **حالةٌ مشتقّةٌ لا تُطلق حدثاً** — وربطُه بمرورِ
`ends_at` كان `ClassSessionStatus::Interrupted` في شكلٍ جديد: قرّاءٌ وكاتبٌ غيرُ موجود، فمفتاحُ
التلعيبِ لا يُمنَح أبداً و`AwardPoints` يعود صامتاً. **ومن نفد وقتُه عند ٨ من ١٠ ليس
«منتهياً»** فلا نقطةَ له، وعرضُ نتيجتِه قراءةٌ تبقى كما هي.

**والبثُّ مخنوقٌ بثانيةٍ لكلِّ غرفة** — SC-006 يطلب ثانيتَين p95.

### `GET /study-rooms/{uuid}/board`

`throttle:adaptive-step`. اللوحةُ عبر HTTP — **الاحتياطُ حين لا سوكِت**، على قاعدةِ `SC-015`
من 010: الشاشةُ تعمل بلا اتصالٍ لحظيٍّ ولو متأخّرةً بتحديث.

## قناةُ البثّ

```php
// routes/channels.php — الملفُّ الوحيدُ الذي يُعدَّد فيه اسمُ قناة (NFR-007 من 010)
Broadcast::channel('study-room-board.{uuid}', …);      // خاصّة، لا قناةَ حضور
```

**⚠️ قناةٌ خاصّةٌ باسمٍ مستقلّ — وليست قناةَ حضور.** `config/reverb.php:90` يضبط
`accept_client_events_from => 'members'`، و`channels.php:78-84` يكتب النتيجةَ بنصِّها: الهمسُ
**يُرفَض على قناةٍ خاصّةٍ ويُقبَل على قناةِ حضور**. فقناةُ حضورٍ هنا تفتح **دردشةً مباشرةً
غيرَ مُراقَبةٍ بين قاصرين** داخلَ الغرفة — بلا `hidden_at`، ولا `ConversationPolicy`، ولا فحصِ
حظر، ولا `chat.moderate`. ولا حاجةَ إلى قائمةِ الأعضاءِ أصلاً: **اللوحةُ هي القائمة**.

**والحارسُ صفُّ مشاركةٍ، لا الأهليّة.** «مؤهَّل» و«مشارِك» سؤالانِ مختلفان: بالأوّلِ يشترك
أيُّ طالبٍ مؤهَّلٍ يحمل الـuuid ويقرأ أسماءَ الجميعِ ودرجاتِهم **بلا انضمامٍ وبلا ظهورٍ لأحد**.

**والقدرةُ قابلةٌ للقراءة**: `JoinStudyRoom` فعلُ كتابةٍ بـ`handle()` واحدة، وكلُّ مدخلٍ في
`channels.php` ينادي قدرةً للقراءة. القطعةُ المشتركةُ `Support/StudyRoomAccess.php` يناديها
الحارسانِ معاً — وإلّا فهو عطلُ «الهجاءَين».

**والغرفةُ تُحَلّ بـ`withoutWorkspaceScope()`** داخلَ الـcallback: سياقُ الطالبِ `null` فالنطاقُ
لا يضيف شرطاً، والاتّكاءُ عليه اتّكاءٌ على لا شيء — القاعدةُ مكتوبةٌ لـ`Conversation` في
`channels.php:46-51`.

**الحمولة** — `board.updated`:

```jsonc
{
  "room_uuid": "c81f…",
  "ends_at": "2026-08-29T18:20:00Z",
  "rows": [
    { "uuid": "p-7f1a…", "name": "سارة", "score": 7, "answered": 8 }
  ]
}
```

**`uuid` هو `study_room_participants.uuid`، لا uuidُ المستخدم.** الثاني مُعرِّفٌ للشخصِ على
مستوى المنصّةِ كلِّها، يُسلَّم إلى أقرانٍ قد يكونون قاصرين؛ والأوّلُ يموت مع الغرفة.

**⚠️ و`name` يُحمَّل بـ`first_name` و`last_name`، لا بـ`name`.** `users` لا يحمل ذلك العمود —
هو accessor — فتحميلٌ مقيَّدٌ بـ`->with('user:id,uuid,name')` يُرجع **اسماً فارغاً**، وقد شحن
ذلك في ستّةِ مواضعَ قبلَ اليوم. واللوحةُ أسوأُ: تُدفَع إلى كلِّ مشترك، فلا شاشةَ يلاحظ فيها
أحدٌ «» أوّلاً. **والتوكيدُ اسمٌ غيرُ فارغ**، لا عددُ صفوف.

**ولا نصَّ سؤالٍ ولا خيارَ إجابةٍ ولا صحّةَ خيارٍ على هذه القناةِ أبداً.** حدُّ الرخصةِ هو
اللوحة. **والتوكيدُ بسنتينلِ ASCII** — نفيٌ عربيٌّ عبر `getContent()` صادقٌ خاوياً.

**والخروجُ عن قاعدةِ «مُعرِّفٌ فقط» مسجَّلٌ في `plan.md › Complexity Tracking`** بأربعةِ قيودٍ
يسقط بسقوطِ أيٍّ منها: اللوحةُ هي محتوى الغرفةِ ومُصرَّحٌ بها لكلِّ من فيها · الغرفةُ تموت بعد
دقائق · قناةٌ خاصّةٌ باسمٍ مستقلّ · والأسئلةُ تبقى على HTTP.
