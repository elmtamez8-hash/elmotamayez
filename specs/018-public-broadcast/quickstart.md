# Quickstart — التحقّق من الفيديو الترويجي للكورس

دليلُ تشغيلٍ وتحقّق. التفاصيل في [contracts/promo-video.md](./contracts/promo-video.md)
و[data-model.md](./data-model.md) ولا تُكرَّر هنا.

---

## المتطلّبات

```bash
cd backend  && php artisan migrate        # هجرةُ إضافةٍ خالصة — لا migrate:fresh
cd frontend && npm run dev                # :3000
cd backend  && php artisan serve          # :8000
```

⚠️ **`migrate` لا `migrate:fresh`**: الهجرة إضافةُ أعمدةٍ بلا ردم، و`migrate` وحدها تثبت
أنها تعمل على قاعدةٍ فيها بيانات — وهو ما سيحدث في الإنتاج.

## السيناريو ١ — الزائرة تشاهد (US1 · SC-001)

1. من `/admin` أو من لوحة المدرّس: الصقْ رابطاً على كورسٍ **منشورٍ لمدرّسٍ معتمَد**.
2. اعتمدْه بحسابٍ يحمل `marketplace.promo.review`.
3. افتحْ `/courses/{uuid}` في **نافذةِ تصفّحٍ خاصّة** — زائرةٌ بلا حساب.

**المتوقَّع**: زرٌّ يظهر. الضغطُ يكشف الإطار. مدخلُ الحجز الذي وضعه ٠٢٣ في مكانه بلا تغيير،
**ولا زرَّ حجزٍ ثانٍ** (FR-013).

**والقياسُ الحاسم قبلَ الضغط** — بلا هذا لا يُصدَّق شيء:

```
DevTools › Network › Filter: 3rd-party    ⇒ صفر طلبٍ إلى مضيف الفيديو
DevTools › Elements › ابحث عن <iframe>    ⇒ غير موجودٍ في DOM
```

ثمّ اضغطْ: الطلبات تظهر الآن، والإطار يدخل DOM. **الترتيب هو الاختبار** (R3).

```bash
cd backend && php vendor/bin/pest tests/Feature/Marketplace   # الحمولة العامّة والallowlist
```

## السيناريو ٢ — الرفض عند الإدخال (FR-007 · FR-008 · SC-002)

الصقْ في حقل الرابط، واحداً بعد واحد:

| المُدخَل | المتوقَّع |
|---|---|
| رابطاً من منصّةٍ أخرى | `422` برسالةٍ عربيّةٍ تقول ما هو المقبول |
| `javascript:alert(1)` | `422` — **ولا صفَّ يُكتب** |
| نصّاً ليس رابطاً | `422` |
| رابطاً صحيحاً بمعاملاتٍ زائدة (`?t=` · `&list=`) | يُقبَل، و**المُخزَّن المُعرِّفُ وحده** |

ثمّ اقرأِ الصفَّ مباشرةً:

```bash
cd backend && php artisan tinker --execute="dump(\App\Modules\Courses\Models\Course::withoutWorkspaceScope()->whereNotNull('promo_video_id')->pluck('promo_video_id'));"
```

**المتوقَّع**: مُعرِّفاتٌ قصيرةٌ وحدها — **صفر `http`، صفر `?`، صفر مسافة**. صفٌّ واحد يحمل
رابطاً كاملاً يعني أنّ الاستخراج لم يقع، وأنّ نصّاً خامّاً يقف على مسافة سطرٍ من `src`.

## السيناريو ٣ — المراجعة تحرس فعلاً (US2 · SC-004 · R5)

| الفاعل | المتوقَّع |
|---|---|
| رابطٌ ملصوقٌ لم يُراجَع → الصفحة العامّة | **لا زرّ** |
| مالك مساحة العمل يحاول الاعتماد | `403` |
| حاملُ `marketplace.promo.review` يعتمد | `200`، والزرّ يظهر |
| المدرّس يلصق **رابطاً آخر** على كورسٍ معتمَد | الحالة تعود `pending` و**الزرّ يختفي فوراً** |

⚠️ **الصفُّ الأخير هو أهمّ ما في هذه الصفحة**: بدونه يبقى الاعتماد سارياً على محتوىً لم يره
أحد، وهو بابُ تبديلٍ يجعل المراجعة كلَّها بلا معنى.

⚠️ **واختبرِ الاتّجاهين**: «مَن يحمله ينجح» لا يقلّ لزوماً عن «من لا يحمله يُردّ». إذنٌ يُصنَّف
بالغياب يمرّ كلّ اختباراته ويحرس صفراً — سابقة `taxonomy.manage` في ٠٠٩ — لأنّ Laravel يفشل
**مفتوحاً** حين لا تُسجَّل السياسة.

## السيناريو ٤ — الصفحة لا تنكسر (FR-015 · SC-006)

| الحالة | المتوقَّع |
|---|---|
| كورسٌ بلا فيديو | الصفحة كاملة، **لا زرّ**، لا موضعٌ فارغ، لا رسالةُ خطأ |
| فيديو حذفه المدرّس من قناته | الزرّ يعمل، والإطار يعرض ما تعرضه المنصّة — **ولا رسالةَ خطأٍ من عندنا** (R8) |
| كورسٌ أُلغي نشره وله فيديو معتمَد | الصفحة `404` كما كانت — الحارس هو `publiclyListed()` نفسه، لا حارسٌ ثانٍ |

## السيناريو ٥ — المدرّس يغادر (FR-012 · R7)

نفِّذْ إخراجَ مدرّسٍ حتى `Completed`، ثمّ:

```bash
cd backend && php artisan tinker --execute="dump(\App\Modules\Courses\Models\Course::withoutWorkspaceScope()->where('created_by', <ID>)->get(['promo_video_id','promo_video_status'])->toArray());"
```

**المتوقَّع**: `null` و`none` على كلّ كورساته. فيديوه يبقى على قناته ملكاً له — نحن نمحو
رابطاً لا فيديو.

⚠️ **واختبارُ هذا يحتاج مساحتَي عملٍ لا واحدة**: `ExecuteTeacherOffboarding` كانت كلّ عباراته
مقيَّدةً بمساحة العمل، فأخفت مساحةُ عملٍ واحدةٍ في التجهيزات عطلاً كاملاً — قاعدةٌ مكتوبةٌ في
`CLAUDE.md` عن كلّ كتابةٍ بإذنٍ منصّيّ.

## البوابات — دفعةً واحدة في النهاية

```bash
cd backend  && php vendor/bin/pest tests/Feature/Courses tests/Feature/Marketplace
cd backend  && ./vendor/bin/pint --test && ./vendor/bin/phpstan analyse
cd frontend && npm test && npx tsc --noEmit
```

⚠️ **لا تُشغَّل حزمتا pest معاً** — تتشاركان قرص الاختبار وتصنعان فشلاً كاذباً.
ولا حزمةَ اختباراتٍ محليّةٍ كاملة: CI يشغّلها؛ يُختبَر ما تغيّر، مرّةً واحدة، في النهاية.

## ما لا يُقاس هنا — ولا يُدَّعى

- **صحّةُ كلّ شكلٍ من أشكال روابط المنصّة**: يُثبَّت بمتّجهاتٍ في `PromoVideoUrl` بلا شبكةٍ ولا
  حساب (‏سابقة `BunnyTokenVectorTest`). ولا يُدَّعى أنّ القائمة شاملة — الشكلُ المجهول
  **يُرفض عند الإدخال**، وهو السلوك الصحيح.
- **سلوكُ مضيفِ «بلا كوكيز» عبر المتصفّحات**: لم يُقَس على أجهزةٍ حقيقيّة، ولا شيء أمنيٌّ يعتمد
  عليه — تفضيلُ خصوصيّةٍ لا حارس.
