# Contract — الفيديو الترويجي للكورس

ثلاثةُ عقود: حقلٌ على حمولةٍ عامّةٍ قائمة، ونقطتا نهايةٍ مصادَق عليهما. **لا نقطة نهايةٍ
عامّةٍ جديدة** — الفيديو حقلٌ على صفحة الكورس التي شحنها ٠٢٣.

---

## ١. الحقل العامّ — امتدادٌ على عقدٍ قائم

**`GET /api/v1/public/courses/{uuid}`** — يخدمها `Marketplace\Actions\Public\ReadPublicCourse`
ابتداءً من `->publiclyListed()`، وهو الحارس الوحيد على هذا المسار.

يُضاف مفتاحٌ واحد إلى `PublicCourseDetailResource`:

```jsonc
{
  // …المفاتيح القائمة كما هي…
  "promo_video_id": "dQw4w9WgXcQ"   // أو null
}
```

| القاعدة | الإلزام |
|---|---|
| القيمة `null` ما لم يكن `status === 'approved'` **و**`id !== null` معاً | FR-006 · data-model |
| `null` لا يفرّق بين «لا فيديو» و«ينتظر المراجعة» | كشفُ الفرق يخبر الزائر بوجود شيءٍ مخفيّ |
| المفتاح يُضاف إلى `PublicFieldAllowlist::COURSE_DETAIL` في التغيير نفسه | `PublicExposureTest` يُسقط البناء بدونه — وهي البوابة |
| **يُنشَر المُعرِّف، لا رابطٌ ولا عنوانُ تضمينٍ جاهز** | R6: عنوانُ التضمين تفصيلُ عرضٍ يُبنى على الطرفين، لا عقدٌ عامٌّ يُجمَّد |
| صفر استعلامٍ إضافيّ | الحقل يأتي مع صفّ الكورس المقروء أصلاً |
| المحدِّد `throttle:public` | قائمٌ على المجموعة، لا يُضاف |

**غير موجودٍ في الحمولة، عمداً**: حالةُ المراجعة، وقتُها، مَن راجَع، الرابط كما لُصق.
كلّها بياناتٌ داخليّة.

---

## ٢. لصق الرابط — المدرّس

**`PUT /api/v1/courses/{course}`** — حقلٌ يُضاف إلى `UpdateCourseRequest`، لا نقطةَ نهايةٍ جديدة.

```jsonc
{ "promo_video_url": "https://…" }   // أو null للمحو
```

| البند | السلوك |
|---|---|
| التفويض | `CoursePolicy::update()` القائمة — يملك الكورس داخل مساحة عمله |
| مدرّسٌ غير معتمَدٍ أو غير منشورٍ في السوق | **يُرفض** (FR-009) — الشرط في `SetCoursePromoVideo`، لا في نموذج الطلب وحده |
| رابطٌ لا يُستخرَج منه مُعرِّف | `422` برسالةٍ عربيّةٍ تقول ما هو المقبول (FR-007) — **رفضٌ عند الإدخال لا عند العرض** |
| نجاح | يُكتب `promo_video_id`، وتُصفَّر المراجعة إلى `pending` **في العبارة نفسها** |
| `null` | يُمحى المعرّف والحالة تعود `none` |
| ما لا يُقبَل أبداً | `promo_video_status` أو `reviewed_at` أو `reviewed_by` في الحمولة — خارج `$fillable` وخارج نموذج الطلب |

⚠️ **التحقّق في الإجراء أيضاً، لا في `FormRequest` وحده**: Filament والبذور تصل الإجراء بلا
نموذجِ طلب، والدستور II صريحٌ في هذا.

**الاستجابة**: `CourseResource` القائم، يحمل `promo_video_id` و`promo_video_status` — هذه
شاشةُ المدرّس، وهو يستحقّ أن يعرف لماذا لا يظهر زرّه.

## ٣. المراجعة — منصّية

**`POST /api/v1/courses/{course}/promo-video/review`**

```jsonc
{ "decision": "approved" | "rejected", "reason": "…" }   // reason مطلوب مع rejected
```

| البند | السلوك |
|---|---|
| التفويض | `Permissions::MARKETPLACE_PROMO_REVIEW` — **إذنٌ منصّيّ**، لا يحمله أيّ دور مستأجر |
| مالك مساحة العمل | `403` — وإلّا اعتمد المدرّس فيديو نفسه وصارت المراجعة اسماً بلا مضمون |
| كورسٌ حالته `none` | `422` — لا شيء يُراجَع |
| القراءة عبر مساحات العمل | المراجع منصّيّ، فالاستعلام يُعلن `withoutWorkspaceScope()` بتعليقٍ يشرح السبب (‏الدستور I) — و`WorkspaceContext::id()` يرجع `last_workspace_id` حتى للمنصّيّ، فبقاء النطاق يعني رؤية كورسات مساحةٍ واحدة |
| نجاح | تُكتب الحالة و`reviewed_at` و`reviewed_by` |

**والسطح نفسه في `/admin`**: إجراءُ صفٍّ على `CourseResource` القائم. ⚠️ ويُكرَّر الحارس على
مورد Filament: `Gate::before` يمرّر المدير الأعلى فوق كلّ سياسة — سابقة `CreditPackageResource`.

⚠️ **ولا يكفي فحصُ الردّ**: إذنٌ يُصنَّف بالغياب يمرّ كلّ اختباراته ويحرس صفراً
(‏`taxonomy.manage` في ٠٠٩). فيُختبَر الاتّجاهان — **مَن يحمله ينجح** ومن لا يحمله يُردّ —
لأنّ Laravel يفشل **مفتوحاً** إلى «لا سياسة تنطبق» حين لا تُسجَّل السياسة.

## ٤. عقد الواجهة

**`PromoVideoButton`** — مكوّن عميلٍ داخل صفحة الكورس الخادميّة.

```ts
{ videoId: string; courseTitle: string }
```

| القاعدة | لماذا |
|---|---|
| المكوّن **لا يُركَّب أصلاً** حين `promo_video_id === null` — الزرّ غائبٌ لا معطَّل | FR-015 · R8: زرٌّ معطَّل يَعِد ثمّ يمنع |
| `<iframe>` **غير موجودٍ في DOM** قبل الضغط | R3: صفر بايت من طرفٍ ثالثٍ لزائرٍ لن يضغط |
| `src` يُبنى من `videoId` وحده، ومضيفُ التضمين ثابتٌ في الكود | **FR-008** — لا نصَّ مستخدمٍ يصل `src` بأيّ حال |
| `title` على الإطار من `courseTitle` | إمكانيّة الوصول: إطارٌ بلا عنوان صندوقٌ مجهولٌ لقارئ الشاشة |
| كشفٌ في الموضع، لا طبقةٌ فوقيّة | R4: لا مكوّن حوارٍ في `components/ui/`، ورفض المستودع بناءَه صراحةً |
| ألوانٌ من `@theme` وحدها | ⚠️ أربعةُ رموزٍ غير معرَّفةٍ شُحنت في هذا المستودع فلم تُطلِ **شيئاً** بصمت. `src/lib/theme-tokens.test.ts` هو البوابة |
| خصائصُ منطقيّة (`ms-*` · `start-*`) لا `ml-*`/`left-*` | الواجهة عربيّةٌ RTL وحدها |
| الاختبار `vitest`، وبـ`fireEvent` لا `userEvent` | سابقتا `ConfirmButton` و`PasswordField` |

**ما يُقاس في الاختبار**: أنّ لا `iframe` قبل الضغط، وأنّ `src` يحوي المعرّف ولا يحوي نصّاً
من الخارج، وأنّ لا زرّ حين `videoId` غائب. ⚠️ والأوّل هو الذي لا يُستغنى عنه: بدونه يمرّ
تنفيذٌ يُركّب الإطار مخفيّاً بـ`hidden` — يبدو صحيحاً ويحمّل الطرفَ الثالث كاملاً.
