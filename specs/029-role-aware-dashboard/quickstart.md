# Quickstart — ٠٢٩ · لوحةٌ تعرفُ من يفتحُها

دليلُ **تحقُّقٍ**، لا دليلُ تنفيذ. كلُّ بندٍ هنا يُشغَّلُ ويُقرَأُ ناتجُه.

## المتطلّبات

```bash
# الخلفيّة (من backend/)
php artisan serve                       # :8000

# الواجهة (من frontend/)
npm run dev                             # :3000 — يُمرِّرُ /api/* إلى :8000
```

⚠️ لا تُشغِّلْ `npm run build` وخادمُ التطويرِ يعمل — كلاهما يكتبُ في `.next/`.
⚠️ ولا تُشغِّلْ مجموعتَي `pest` معاً — تتقاسمانِ قرصَ الاختبارِ وتُلفِّقانِ فشلاً.

بياناتُ الدخولِ التجريبيّةُ وأوامرُ التشغيلِ الكاملةُ في ذاكرةِ المشروع (`running-mteatch-locally`).

## ١ · البوّاباتُ الأربع

```bash
# backend/
php vendor/bin/pest tests/Feature/LiveSessions tests/Feature/Notifications
./vendor/bin/pint --test
./vendor/bin/phpstan analyse

# frontend/
npx tsc --noEmit
npm test -- src/app/\(app\)/\(shell\)/dashboard
```

`npm test` هو السطحُ الذي يرى أعطالَ هذه الميزة: ثانيتان، بلا بناءٍ وبلا خادِمَين. Playwright
يجيبُ عن سؤالٍ آخرَ (المنتَجُ من طرفٍ إلى طرفٍ والوصوليّة) وليس حلقةَ التطوير.

## ٢ · التحقّقُ اليدويّ — ثلاثةُ حسابات، ثلاثُ شاشات

الاختبارُ الحقيقيُّ لهذه الميزةِ هو **فتحُ الشاشةِ بثلاثةِ حسابات**. لا اختبارَ آليٌّ يرى «هل
هذه الشاشةُ صحيحةٌ لهذا الشخص».

### طالب

1. سجّلِ الدخولَ بحسابِ طالبٍ عندَه حصّةٌ محجوزةٌ قادمةٌ وكورسانِ جاريان.
2. **يُتوقَّع**: بطاقاتُ العدِّ · رصيدٌ **لكلِّ كورسٍ على حدة** · جدولُ حصصٍ قادمةٍ بالأقربِ أوّلاً ·
   أشرطةُ تقدُّم · آخرُ الإشعاراتِ · آخرُ الطلبات.
3. **لا يُتوقَّع**: أيُّ رقمٍ يجمعُ رصيدَ كورسَين · أيُّ بطاقةٍ بلا رابطٍ إلى شاشتِها.

### مدرّس

1. سجّلِ الدخولَ بحسابِ مدرّسٍ عندَه حصصٌ هذا الأسبوعُ وأوراقٌ بانتظارِ التصحيح.
2. **يُتوقَّع**: «حصصي» تحملُ حصصَه هو · أعمدةُ سبعةِ أيّامٍ · عددُ الأوراقِ · طلباتُ الحصصِ
   الخاصّة.
3. **لا يُتوقَّع**: «كورسات جارية ٠» · «نظرةٌ عامّةٌ على تقدّمِك الدراسيّ» · حصّةُ زميلٍ تحتَ
   «حصصي».

### وليُّ أمر

1. سجّلِ الدخولَ بحسابِ وليِّ أمرٍ مرتبطٍ بابنٍ **له حساب** وإذنُ «المواعيدُ والحصص» ممنوح.
2. **يُتوقَّع**: اسمُ الابنِ · جدولُه القادمُ · نسبةُ حضورِه · رصيدُه · آخرُ كشفِ تقديراتِه.
3. **لا يُتوقَّع**: دعوةُ دخولٍ إلى حصّةِ الابن · إشعاراتُ الابنِ نفسِه · أيُّ بطاقةٍ لإذنٍ غيرِ
   ممنوحٍ معروضةً فارغة.

## ٣ · القياساتُ التي تُثبِتُ المعاييرَ رقماً

### `SC-003` — صفرُ ردودِ «ممنوع» في خمسِ حالات

افتحِ اللوحةَ بكلِّ حسابٍ من: طالب · مدرّس · وليّ أمر · مساعدِ مدرّس · حسابٍ بلا دورٍ مسجَّل،
واقرأْ لسانَ الشبكةِ في المتصفّح.

**النجاح**: ولا `403` واحد.

### `SC-004` — عزلُ العطل

في اختبارِ المكوّنِ لا في المتصفّح: اجعلْ **مصدراً واحداً** يرفض، وأكِّدْ أنّ بقيّةَ البطاقاتِ
معروضة. كرِّرْ لكلِّ مصدرٍ على حدة.

**النجاح**: فشلٌ واحدٌ ⇒ بطاقةٌ واحدةٌ في حالةِ فشلٍ وكلُّ ما عداها جاهز.

### `SC-005` — العدُّ الصادق

احسبْ في قاعدةِ البياناتِ عددَ تسجيلاتِ طالبٍ يتجاوزُ صفحةً واحدة، ثمَّ اقرأْ بطاقةَ العدّ.

**النجاح**: **فارقُ صفر** — لا رقمَ ١٥.

### `SC-006` — حراسةُ الوِلايةِ في الاتّجاهَين

```bash
php vendor/bin/pest --filter="ChildScheduleGuard"
```

**النجاح**: وليٌّ مأذونٌ يقرأُ ابنَه `200`؛ ووليٌّ **بإذنٍ آخرَ** أو عن **حسابٍ ليس ابنَه** يُردُّ
`403` — والردُّ لا يحملُ اسماً ولا يفرِّقُ بينَ «ليس ابنَك» و«لا وجودَ له».

### `SC-008` — الألوانُ والوصوليّة

```bash
npm test -- src/lib/theme-tokens
```

**النجاح**: كلُّ رمزِ لونٍ يستعملُه الرسمُ معرَّفٌ في `@theme`.

⚠️ **هذا الاختبارُ هو الحارسُ الوحيد**: صنفُ لونٍ يسمّي رمزاً غيرَ معرَّفٍ لا يرسمُ شيئاً **بصمت**
— لا خطأَ ولا تحذيرَ ولا فرقَ في لقطةٍ. شحنَ هذا العطلُ ثلاثَ مرّاتٍ في هذا المستودع.

### `SC-009` — سقفُ الاستعلامات

```bash
php vendor/bin/pest --filter="QueryBudget"
```

**النجاح**: كلفةُ كلٍّ من القراءتَينِ الجديدتَينِ ثابتةٌ بينَ ابنٍ واحدٍ وثلاثةِ أبناء، وبينَ
حصّةٍ واحدةٍ وعشرين.

⚠️ حَمِّ الطلبَ **حتّى يستقرَّ** قبلَ القياس. طلبُ تحميةٍ واحدٌ لا يكفي — وحينَ يهتزُّ السقفُ
بواحدٍ فالمطلوبُ إيجادُ الاستعلامِ لا رفعُ الرقم.

## ٤ · الفخُّ الذي يجعلُ التحقّقَ اليدويَّ كاذباً

**تغييرٌ محفوظٌ ولا يظهرُ ⇒ `Ctrl+Shift+R`، لا إعادةُ تشغيلِ الخادم.** المتصفّحُ يحتفظُ بالحزمةِ
القديمةِ عبرَ إعادةِ التحميلِ العاديّةِ وعبرَ إعادةِ تشغيلِ خادمِ التطويرِ وعبرَ حذفِ `.next` —
ويظهرُ التغييرُ فوراً بإعادةِ تحميلٍ قسريّة. تحقَّقْ من القرصِ قبلَ تصديقِ أثرِ خطأ.
