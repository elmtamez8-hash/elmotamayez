# API Contracts — ٠٢٩ · لوحةٌ تعرفُ من يفتحُها

كلُّ ردٍّ عبرَ API Resource، وكلُّ معرَّفٍ ظاهرٍ **uuid** لا رقماً تسلسليّاً (المبدأ السادس).

**السطحُ الجديدُ مسارانِ اثنان.** كلُّ ما عداهما قراءاتٌ قائمةٌ تُستدعى كما هي — وقائمتُها في
القسمِ (ج) لأنّ «ما لا يتغيّرُ» جزءٌ من العقدِ بقدرِ ما يتغيّر.

---

## أ · مسارانِ جديدان — قراءاتُ وليِّ الأمرِ عن ابنِه

الشكلُ مأخوذٌ حرفيّاً من `GET /billing/children/balance`: **مسارٌ منفصلٌ** يحملُ الفحصَ،
و`?student=` **مطلوب**، و**403** لا 404 حينَ لا يكونُ الابنُ ابنَه — الفرقُ بينَ الردَّينِ يخبرُ
قارئاً غيرَ مأذونٍ إن كان الـuuid يسمّي شخصاً حقيقيّاً (`FR-005`).

### `GET /api/v1/schedule/children?student={uuid}`

`auth:sanctum` · إذنُ الوِلاية **`schedule`**

```jsonc
{
  "data": [
    {
      "uuid": "…",                          // الحجز
      "class_session": {
        "uuid": "…",
        "title": "الفصل الثالث — المتجهات",
        "starts_at": "2026-09-08T16:00:00Z",
        "ends_at":   "2026-09-08T17:00:00Z",
        "status": "scheduled",
        "room_closed": false,
        "course":  { "uuid": "…", "title": "الفيزياء" },
        "teacher_name": "سامي عبد الله"
      }
    }
  ]
}
```

- ⚠️ **مَورِدٌ ضيّقٌ خاصٌّ بهذه القراءة، لا مَورِدُ الحصّةِ العامّ.** المَورِدُ العامُّ يحملُ
  `join_open` و`unlock_open`/`unlock_reason` و`my_booking` و`seats` و`recording.lesson_uuid` —
  وكلُّها محسوبةٌ **عن القارئ**: فوليُّ الأمرِ يقرأُ `my_booking = null` عن حصّةٍ ابنُه محجوزٌ
  فيها، و`join_open = true` يدعوه إلى غرفةٍ لا يدخلُها، ورابطَ تسجيلٍ يُجيبُه `404` لأنّه ليس
  مسجَّلاً ولا عضواً. الحقولُ السبعةُ أعلاه هي الحمولةُ كاملةً.
- يعبُرُ حدودَ مساحاتِ العملِ عمداً — للابنِ جدولٌ واحدٌ عبرَ كلِّ مدرّسيه — وحارسُه ملكيّةُ
  الصفِّ **وَ** الإذن (`FR-020`). التجاوزُ معلَّلٌ في مكانِه ومغطًّى باختبار.
- الترتيبُ بالأقربِ أوّلاً، وسقفٌ افتراضيّ.

**التنفيذ**: المتحكّمُ يحلُّ الابنَ بدليلِ الوِلاية، ثمَّ يُنادي **`GetStudentSchedule` القائمَ
كما هو** — «حصصُ طالبٍ قادمة» سؤالٌ واحدٌ ولا يُكتَبُ مرّتَين.

**الردود**: `200` · `422` بلا `student` · `403` لغيرِ ابنِه أو بلا إذنِ `schedule`.

**الحالاتُ الفارقةُ في الاختبار** — وبدونِ الأولى يمرُّ الاختبارُ على بناءٍ بلا تجاوزِ نطاقٍ فيه
إطلاقاً، لأنّ وليَّ الأمرِ الخالصَ سياقُه `null` والنطاقُ لا يضيفُ شرطاً:

| الحالة | المتوقَّع |
|---|---|
| وليٌّ مأذونٌ **بسياقٍ محلول** يشيرُ إلى مساحةٍ **غيرِ** مساحةِ حصّةِ الابن | `200` والصفوفُ كاملة |
| وليٌّ يحملُ إذناً **آخرَ** لا `schedule` | `403` |
| وليٌّ يسمّي حساباً **ليس ابنَه** | `403`، بلا اسمٍ وبلا تفريقٍ عن «لا وجودَ له» |
| **مدرّسُ الابنِ نفسُه** (مسجَّلٌ عندَه، وليس وليّاً) | `403` — اتّجاهُ «(١)» في المبدأ الأوّل |

### `GET /api/v1/attendance/children/summary?student={uuid}&days=30`

`auth:sanctum` · إذنُ الوِلاية **`attendance`**

```jsonc
{
  "data": {
    "window_days": 30,
    "present": 11, "late": 2, "absent": 1, "excused": 1,
    "total": 15,
    "rate_pct": 93          // مشتقّةٌ من الأربعةِ فوقَها، وتُرسَلُ معها لا بدلاً عنها
  }
}
```

- الفئاتُ الأربعُ هي حالاتُ الحضورِ القائمةُ حرفيّاً.
- **`withoutWorkspaceScope()` معلَّلٌ في مكانِه**: `attendances` مملوكٌ لمساحةِ العمل، ولابنٍ
  يدرسُ عندَ ثلاثةِ مدرّسينَ سجلُّ حضورٍ واحد. والحارسُ مفتاحُ الطالبِ والإذنُ — لا استثناءُ صفِّ
  المضيف، فاستعلامٌ مفتاحُه الابنُ لا يلتقطُ صفَّ المدرّسِ أصلاً.
- `days` اختياريّةٌ بمدًى مقيَّد؛ الافتراضُ ٣٠.
- ⚠️ الحدُّ الأعلى `< اليومُ + يوم`، لا `<= اليوم`: العمودُ طابعُ وقتٍ والحدُّ تاريخ.

**الردود**: كما فوق، بإذنِ `attendance` بدلَ `schedule`، وبالحالاتِ الفارقةِ الأربعِ نفسِها.

## ب · حمولةٌ قائمةٌ تُوسَّعُ بحقلٍ واحد

### `UserResource` — يُضافُ

```jsonc
"teacher_profile_uuid": "9c1f…" | null
```

`null` تعني «لا يستضيفُ حصصاً». تُقيِّدُ بها الواجهةُ قراءةَ الحصصِ على المضيف، وتُفرِّقُ بها
بينَ **مدرّسٍ بلا حصصٍ هذا الأسبوع** و**مساعدٍ لا يستضيفُ شيئاً** — جملتانِ مختلفتانِ على الشاشة.

إضافةٌ لا تعديلٌ كاسر.

## ج · قراءاتٌ قائمةٌ تُستدعى كما هي (لا تعديلَ في أيٍّ منها)

| القراءة | من يستدعيها | ما يُقرَأُ منها |
|---|---|---|
| التسجيلات | الطالب | الصفوفُ الخمسةُ الأولى + `meta.total` |
| الشهادات | الطالب | الصفوفُ الخمسةُ الأولى + `meta.total` |
| أرصدةُ الكورسات | الطالب | كلُّ الصفوف — `is_withheld` أوّلاً |
| رصيدُ الأبناء `?student=` | وليُّ الأمر | كما فوق، لابنٍ مأذونٍ في `payments` |
| جدولُ الطالب | الطالب | خمسةُ صفوفٍ قادمة |
| الحصص `?teacher=&from=&to=&order=asc` | المدرّس | جدولُه + عدُّ الأسبوعِ للرسم |
| الحصص `?from=&to=&order=asc` (بلا `teacher`) | المساعد | حصصُ المساحة، بعنوانٍ يقولُ ذلك |
| طابورُ التصحيح `per_page=1` | المدرّس | `meta.total` وحدَه |
| طابورُ الحصصِ الخاصّة `?status=pending&per_page=1` | المدرّس | `meta.total` وحدَه |
| أرصدةُ طلّابِ المساحة | المدرّس/المساعد بإذنِ الرصيد | عددُ المحجوبين |
| الإشعارات | الجميع | خمسةُ صفوف؛ غيرُ المقروءِ أوّلاً |
| الطلبات | الطالب · وليُّ الأمر | ثلاثةُ صفوف |
| روابطُ الأسرة | وليُّ الأمر | المرتبطونَ بحسابٍ فقط (`student_uuid` موجود) |
| كشفُ التقديرات `?student=` | وليُّ الأمر | آخرُ كشفٍ منشور |

## د · إصلاحُ عقدٍ لازمٌ لـ`FR-012`

**قراءةُ التسجيلاتِ لا تُرسِلُ `meta` اليوم.** تُعيدُ `response()->json(Resource::collection($paginator))`،
وهي الصيغةُ التي **لا تستدعي `toResponse()`** فتُسقِطُ `links` و`meta` بصمت. بلا `meta` لا يوجدُ
عددٌ صادقٌ يُعرَض.

**التغيير**: `->response()->getData(true)` — الصيغةُ المستعمَلةُ في قراءةِ الشهاداتِ سلفاً.

⚠️ **والمقيسُ أنّها تُسقِطُ الغلافَ كلَّه لا `meta` وحدَها**: المفاتيحُ العليا `[0]` — مصفوفةٌ
عاريةٌ — بينما الشهاداتُ `["data","links","meta"]`. والقرّاءُ **الثلاثةُ** يقرؤونَ `res.data ?? []`
⇒ **صفرُ صفوفٍ لكلِّ طالبٍ على المنصّة**: بطاقتا اللوحةِ ٠، وشاشةُ «تعلّمي» خاليةٌ، ومنتقي
الكورساتِ في شراءِ الرصيدِ خالٍ. فهذا **إصلاحُ عطلٍ مشحون**، لا تحسينُ عقدٍ من أجلِ العدّ.

⚠️ **وصفرُ اختباراتٍ تلمسُ هذا الفهرسَ في الشجرةِ كلِّها** — وهو سببُ بقائِه. يُضافُ اختبارٌ لشكلِ
الردِّ مع الإصلاح.

القرّاءُ الثلاثةُ: صفحةُ التسجيلاتِ · صفحةُ شراءِ الرصيدِ · اللوحة — ويُعدَّلونَ في التغييرِ نفسِه.

## هـ · ما لا يُضافُ في هذه المرحلةِ عن قصد

| السطحُ الغائب | لماذا |
|---|---|
| `GET /manage/students` وعدَدُ طلّابِ المدرّس | لا مسارَ ولا شاشة؛ بناؤُهما توسيعُ نطاقٍ لبطاقةِ رقمٍ واحدة |
| مُرشِّحُ حالةٍ على قراءةِ الطلبات | البطاقةُ التي كانت ستستعملُه سقطَت: لا شاشةَ اعتمادٍ في التطبيق |
| مسارٌ واحدٌ يجمعُ اللوحةَ كلَّها | يُعيدُ إنشاءِ عطلِ «قراءةٌ ترفضُ ⇒ الصفحةُ تسقط» في الخادمِ هذه المرّة (`FR-013`) |
| بثٌّ لحظيٌّ للوحة | الجرسُ نبضُ الجلسة، والإشعاراتُ تنشرُ حدثاً محلّيّاً عندَ كلِّ تغيير |
