# Quickstart — التحقّق من تسوية المدرّس

**Feature**: `014-teacher-settlement` · **Date**: 2026-08-06

دليل تشغيل وتحقّق. تفاصيل الحقول في [`data-model.md`](./data-model.md) والمسارات في
[`contracts/api.md`](./contracts/api.md).

## المتطلّبات

```bash
cd backend
php artisan migrate:fresh --seed        # يشمل صلاحيات وقوالب إشعارات هذه المرحلة
php artisan serve                       # :8000
```

> الواجهة: `npm run dev` في `frontend/` — و**لا** تُشغّل `npm run build` وخادم التطوير معاً.

## البوابات الأربع

```bash
cd backend
php vendor/bin/pest
./vendor/bin/pint --test
./vendor/bin/phpstan analyse
cd ../frontend && npx tsc --noEmit
```

## اختبارات هذه المرحلة

**مسارات ملفّات لا `--filter`**: أسماء الاختبارات إنجليزية، و`--filter` بنصّ عربي يعيد
**صفر اختبار ونجاحاً** — وهو أسوأ من الفشل لأنه يبدو أخضر. الدرس دُفع ثمنه في 005.

```bash
php vendor/bin/pest tests/Feature/Settlement            # كل المرحلة
php vendor/bin/pest tests/Feature/Settlement/ContextIsolationTest.php   # NFR-008 — الأهم
php vendor/bin/pest tests/Feature/Settlement/AccrualTest.php
php vendor/bin/pest tests/Feature/Settlement/RateVersioningTest.php
php vendor/bin/pest tests/Feature/Settlement/PeriodCloseTest.php
php vendor/bin/pest tests/Feature/Settlement/StatementPayloadTest.php
php vendor/bin/pest tests/Feature/Settlement/QueryBudgetTest.php
```

> `Queue::fake()` إلزامي في أي اختبار يمسّ خطّاً زمنياً: `->delay()` **يُنفَّذ فوراً** على
> اتّصال الطابور `sync`، فوظيفة الإغلاق تعمل داخل الفعل الذي جدولها وتنهار الخطّة إلى
> اختبار أخضر يثبت العكس.

## سيناريوهات التحقّق

### ١ — الوحدة تُولَّد بالمقعد لا بالحاضر (`SC-005ب`)

حصة جماعية بعشرة مقاعد مُجمَّدة، يحضر ستة. أغلِق الحصة.

**المتوقّع**: **عشر** وحدات. الرقم يُقارَن بـ`class_sessions.billable_seats`، لا بعدد صفوف
الحضور — فالاختبار الذي يعدّ الحضور يمرّ اليوم ويخفي العطل غداً.

### ٢ — حصة لم يُنفّذها المدرّس (`SC-005د`)

حالتان: لم يدخل · دخل وغادر قبل المدة المطلوبة.

**المتوقّع**: صفر وحدة في الحالتين. و`SessionDelivered` **لا يُطلَق** أصلاً — تحقّق منه
بـ`Event::fake()` كي يثبت الاختبار أن الشرط في 005 حيث وُضع لا في مستمع هنا.

### ٣ — التعليق حتى اكتمال الحزمة (`SC-005هـ`)

ثلاث حالات: `recording_status = pending` → معلَّقة · `published` → مُفرَج عنها تلقائياً
بلا تدخّل · `failed` → **مُفرَج عنها** و`recording_fault = true`.

**المتوقّع**: الثالثة هي المهمة — عطل المزوّد ليس خصماً من المدرّس (`FR-008ج`).

### ٤ — استرداد الطالب لا يلمس الدفتر (`SC-003`, `SC-004`)

نفّذ حصة، ولّد وحداتها، ثم نفّذ استرداداً/خصماً/كوبوناً على جانب الطالب.

**المتوقّع**: الدفتر **بفارق صفر** قبل وبعد. المنصة هي البائع فهي من يحمل المخاطرة.

### ٥ — تغيير السعر لا يعيد تسعير الماضي (`SC-005`, `SC-005أ`)

نفّذ حصصاً · ارفع السعر (لا يسري) · اعتمده · نفّذ حصصاً أخرى.

**المتوقّع**: المجموعة الأولى بمبلغها القديم حرفياً، والثانية بالجديد. وبين الرفع والاعتماد:
صفر أثر.

### ٦ — عزل السياقين (`SC-009`, `SC-007`) — **البوابة الحاكمة**

```bash
php vendor/bin/pest tests/Feature/Settlement/ContextIsolationTest.php
```

ثلاث حالات: صفر مفتاح خارجي بين الجدولين · صفر ذكر لنماذج الفوترة داخل
`app/Modules/Settlement/` · صفر حقل خارج القائمة المصرّح بها في كل حمولة تصل مدرّساً
(الكشف **والتصدير**).

**تحقّق من أن الحارس يحرس فعلاً**: أضف مؤقتاً حقلاً من سياق الفوترة إلى مورد الكشف وشغّل
الاختبار — إن مرّ، فالحارس زينة. أعِد الحقل بعدها. (هذه الخطوة أنقذت ميزانية الاستعلامات في
005 من أن تكون خضراء بلا معنى.)

### ٧ — إعادة تشغيل دورة التسوية (`SC-014`, `SC-015`)

أغلِق الفترة مرتين، ثم سجّل صرفاً مرتين، ثم فترة صافيها سالب.

**المتوقّع**: إغلاق واحد · صرف واحد · صفر صرف سالب، والسالب مُرحَّل إلى الفترة التالية.

### ٨ — الكشف عبر الواجهة

- `/manage/settlement` — الكشف بالفترة الجارية.
- ابحث في الصفحة عن أي رقم يخصّ دفع طالب: **يجب ألا يوجد**.
- مساعد مدرّس يفتح المسار نفسه → **٤٠٣**، لا صفحة فارغة.

### ٩ — الأداء (`SC-016`, `NFR-011`)

ابذر ١٠٬٠٠٠ وحدة لمدرّس واحد واقرأ الكشف.

**المتوقّع**: أقل من ثانية، وعدد استعلامات **ثابت** لا يتحرّك مع عدد الوحدات. تُقاس ميزانية
الاستعلامات **بمقارنة حجمين** (١٠٠ وحدة مقابل ١٠٬٠٠٠) لا برقم ثابت — الرقم الثابت يسمح
لـN+1 بالاختباء داخل السماحية.
