# Quickstart: ٠٣٤ — الإدارةُ تملكُ التسجيل

ثلاثُ مشياتٍ، واحدةٌ لكلِّ قصّة. **كلُّ مشيةٍ تحملُ شرطَها معها** — بندٌ يُمشى عليه مرّةً في الفصلِ ولا يقولُ شرطَه هو بندٌ يُعادُ اكتشافُ فخِّه في كلِّ مرّة.

## التهيئة

```bash
cd backend && php artisan serve          # :8000 · /admin
cd frontend && npm run dev               # :3000
```

⚠️ **وفخُّ التهيئةِ مقيسٌ ومكتوب: اختبارُ أيِّ شاشةِ إدارةٍ هنا يحتاجُ مساحتَي عملٍ، وموظَّفاً يملكُ إحداهما.** `WorkspaceContext::id()` يسقطُ إلى `users.last_workspace_id` لكلِّ مستخدمٍ وموظَّفُ الإدارةِ منهم — فتركيبةٌ بمساحةٍ واحدة، أو بموظَّفٍ لا مساحةَ له، **تمرُّ على البناءِ المعطوبِ كلَّه**. كلّفَت ٠٢٤ خمسَ طبقاتٍ من العطبِ مخفيّةً بعضُها خلفَ بعض.

---

## ١) الإدارةُ تُسنِدُ طالباً إلى مجموعة (US1)

**الشرطُ المُسبَق**: طالبٌ له **تسجيلٌ قائمٌ** في كورسٍ، و**لا عضويّةَ** له فيه — وهو ما يُنتِجُه اعتمادُ طلبِ **شراءِ كورس** (لا طلبُ اشتراك، فذاكَ يُسنِدُ أصلاً منذُ ٠٢٧).

```
/admin → «إسنادُ طالبٍ إلى مجموعة»
  اختَرِ الكورسَ ⇒ اختَرِ الطالبَ (ومَن لا مجموعةَ له مميَّز) ⇒ اختَرِ المجموعةَ ⇒ أسنِدْ
```

**المتوقَّع**

| | |
|---|---|
| العضويّة | صفٌّ مفتوحٌ في `cohort_memberships` بـ`workspace_id` **المجموعةِ** لا الموظَّف |
| المقعد | `cohorts.members_count` زادَ واحداً |
| التاريخ | حدثُ `assigned` باسمِ الموظَّف |
| الطالب | إشعارٌ بالمجموعةِ ومواعيدِها، وجدولُه يعرضُ حصصَها |

**والرفضانِ يُمشى عليهما أيضاً**: طالبٌ **غيرُ مسجَّل** ⇒ «التسجيلُ يسبقُ العضويّة» · مجموعةٌ **مكتملة** ⇒ «مكتملة»، والعضويّةُ القائمةُ لم تُمَسّ.

⚠️ **ومجموعةٌ `closed` وجهةٌ مشروعة** — «مغلقة» جملةٌ عن البابِ لا عن الغرفة، وهي للإدارةِ كما هي للمدرّس. مؤرشَفةٌ مرفوضةٌ للاثنَين.

---

## ٢) لا انضمامَ ذاتيّاً (US2)

```
صفحةُ الكورسِ بحسابِ طالبٍ مسجَّل  ⇒  مجموعاتٌ ومواعيدُ بلا زرِّ انضمام
                                      + جملةٌ تقولُ مَن يُسنِدُ ومَن يُراجَع
                                      + المنهجُ مفتوحٌ تحتَها
```

ثمّ الطلبُ المباشرُ متجاوزاً الشاشة:

```bash
# قبلُ
php artisan tinker --execute="echo \App\Modules\Learning\Models\CohortMembership::withoutWorkspaceScope()->count();"

curl -X POST http://localhost:8000/api/v1/cohorts/{uuid}/join -H "Authorization: Bearer {token}"

# بعدُ — العددُ نفسُه
```

⚠️ **والتوكيدُ الثاني هو المهمّ.** فشلُ هذا البندِ **كتابة**: `201` بدلَ `404` يعني عضويّةً حقيقيّةً أُنشِئَت. توكيدٌ على رمزِ الحالةِ وحدَه يمرُّ على تنفيذٍ يكتبُ الصفَّ ثمّ يشتكي — العطبُ نفسُه الذي وقعَ في ٠٢٧ · T075.

⚠️ **ولا اختبارَ واحداً في الشجرةِ يمسُّ هذا المسارَ اليوم** (قِيسَ: صفرُ `postJson` عليه؛ الستّةَ عشرَ ملفّاً تستدعي `JoinCohort` **الفعلَ**). فمسارٌ لا يقيسُه شيءٌ يُعادُ فتحُه بلا أن يحمرَّ شيء — الاختبارُ الجديدُ جزءٌ من التسليم.

## ٣) الإدارةُ تُنشئُ باقةً بالنيابة (US3)

```
/admin → الباقات → «باقة جديدة»
  المدرّس (مطلوب) · الكورس · المدّة · نطاقُ التغطية · نوعُ الحصّة · السعر
```

**المتوقَّع**

| | |
|---|---|
| الصفّ | `plans.workspace_id` = مساحةُ **المدرّسِ المختار**، لا مساحةُ الموظَّف |
| المدرّس | يراها في `/manage/plans`، ويصلُه إشعارُ «باقةٌ أُنشِئَت باسمِك» |
| الطالب | تظهرُ في باقاتِه كأيِّ باقةٍ أخرى |

**والرفضُ يُمشى عليه**: حقلُ المدرّسِ فارغاً ⇒ تُرفَض.

⚠️ **وأوّلُ ما يُتحقَّقُ منه هو الإشعارُ نفسُه، لا وصولُه بلا خطأ.** إشعارٌ بلا قالبٍ معتمَدٍ **يسقطُ صامتاً** في هذه المنصّة — لا خطأ، ولا سطرَ سجلّ. فيُقرَأُ صفُّ `notifications` للمدرّسِ مباشرةً:

```bash
php artisan tinker --execute="echo \App\Modules\Notifications\Models\Notification::where('type','plan_created_for_you')->count();"
```

⚠️ **وقاعدةُ الإنتاجِ تحتاجُ هجرةَ الردمِ** (`seedMissing()`): بذرةُ القوالبِ لا تُشغَّلُ إلّا مع `migrate:fresh --seed`، والاختبارُ يبذرُها قبلَ كلِّ حالة — فالاختبارُ أخضرُ فوقَ جدولٍ قد لا يملكُه الإنتاج. **المرّةُ السادسةُ لهذه الآليّةِ في هذه الشجرة.**
