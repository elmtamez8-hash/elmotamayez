# العقد: `Shared\Contracts\EnforcesPerUserCaps`

**الميزة**: `038-session-log-retention` · **التاريخ**: ٢٠٢٦-٠٩-٢٢

⛔ **هذا هو السطحُ العامُّ **الوحيدُ** الذي تزيدُه هذه الميزة.** ولا نقطةَ نهايةٍ جديدةٌ ولا صلاحيّةٌ ولا جدول. وقد كُتِبَ له بندٌ في «تتبُّعُ التعقيد» في الخطّة، لأنّ الدستورَ (VI) يشترِطُ أن يكونَ كلُّ عقدٍ ظاهرٍ مقصوداً.

---

## لماذا عقدٌ ثانٍ ولم تكفِ `PersonalDataOwner`

`expire()` توقيعُها محورُه `$before` — أي **العمر**. والسقفُ سؤالٌ عن **العدد** («أحدثُ N لكلِّ مستخدِم»)، ولا موضعَ له فيه.

وثلاثةُ بدائلَ أقصرَ رُفِضَت لسببٍ **مقيسٍ** لا ذوقيّ، وتفصيلُها في `research.md` · ر-٢:

| البديل | لماذا رُفِض |
|---|---|
| حشرُ السقفِ داخلَ `expire()` | المكنسةُ تجمعُ الناتجَ في العمودِ الذي **تُعلِنُه الفئة** (`$rows[$behaviour->value]`)، فصفوفٌ حُذِفَت تُسجَّلُ في `rows_anonymised` — كذبٌ في سجلِّ التدقيق |
| صفُّ كتالوجٍ ثانٍ سلوكُه `Delete` | `expires()` تشترطُ `retain_days`، فيُكتَبُ رقمُ أيّامٍ لا يقرؤُه أحدٌ ويراه المشغِّلُ ساري المفعول |
| دالّةٌ سادسةٌ في `PersonalDataOwner` | عشرُ وحداتٍ تكتبُ `return 0;` لسؤالٍ لا يخصُّها |

**والسابقةُ في هذا المستودَع**: `SendsVerificationCodes` — قدرةٌ **تُسأَلُ بالتسجيلِ لا بـ`instanceof`**، فقناةٌ لا تحملُ رمزاً ببساطةٍ لا تُنفِّذُها.

## التوقيع

```php
<?php

declare(strict_types=1);

namespace App\Shared\Contracts;

/**
 * وحدةٌ تحرسُ سقفَ صفوفٍ لكلِّ مستخدِم — لا مدّةَ احتفاظ.
 *
 * ⛔ منفصلٌ عن {@see PersonalDataOwner} لأنّ `expire()` تسألُ عن العمرِ
 * (`$before`)، والسقفُ يسألُ عن العدد. وحشرُه هناك يجعلُ صفوفاً محذوفةً
 * تُسجَّلُ في `rows_anonymised` — وصفُّ `retention_sweep_runs` سجلُّ تدقيق.
 *
 * ⚠️ والقائمةُ المُعفاةُ تُمرَّرُ أعداداً كما تُمرَّرُ في `expire()` تماماً:
 * `Compliance` لا تُسمّي جدولَ أحد، ولا وحدةٌ تستورِدُ `LegalHold`.
 */
interface EnforcesPerUserCaps
{
    /**
     * @param  int  $limit  أقصى ما يُمَسُّ في نداءٍ واحد
     * @param  list<int>  $exemptUserIds  أصحابُ حظرٍ قضائيٍّ ساري — لا يُمَسُّ لهم صفّ
     * @return int عددُ الصفوفِ المحذوفة
     */
    public function enforceCaps(int $limit, array $exemptUserIds = []): int;
}
```

---

## سلوكٌ مُلزِمٌ على كلِّ مُنفِّذ

1. **يقرأُ رقمَه بنفسِه.** المكنسةُ لا تعرفُ ما هو السقفُ ولا أينَ يسكن. والصيغةُ `PlatformSettings::get('<key>', <default>)`.
2. **صفرٌ أو ما دونَه ⇒ لا سقف.** يرجِعُ `0` ولا يحذفُ شيئاً. مشغِّلٌ يُفرِّغُ الحقلَ يقصدُ إيقافَ الميزةِ لا تفريغَ الجدول، واتّجاهُ الخطأِ هنا لا رجعةَ فيه.
3. **يرجِعُ عددَ ما حُذِفَ فعلاً** — لا ما كانَ مُرشَّحاً. المكنسةُ تجمعُه في `rows_deleted`.
4. **أقلُّ من `$limit` يعني «فرغتُ»** — التعريفُ نفسُه الذي تستعملُه `RunRetentionSweepJob::walk()` مع `expire()`، وهو ما يجعلُ مروراً مقطوعاً قابلاً للاستئنافِ بالبناء.
5. **يحترِمُ `$exemptUserIds` حذفاً.** حذفٌ تحتَ حظرٍ قضائيٍّ هو بالضبطِ ما يمنعُه الحظر.
6. **مُتقارِبٌ (idempotent)**: النداءُ الثاني بعدَ الأوّلِ يرجِعُ `0`.

## التسجيل

```php
// IdentityServiceProvider::register()
$this->app->tag([IdentityPersonalData::class], ['compliance.personal_data']);   // قائم
$this->app->tag([AuthSessionRetention::class], ['compliance.per_user_caps']);   // جديد
```

⚠️ **وسمٌ ثانٍ لا `instanceof` على الموسومِ الأوّل.** الوسمُ هو التصريح، وفحصُ النوعِ تصريحٌ ضِمنيٌّ يصحُّ صدفةً — والسابقةُ مكتوبةٌ في هذا المستودَعِ بنصِّها.

## المرورُ الثاني في `RunRetentionSweepJob::handle()`

يُضافُ **بعدَ** حلقةِ الفئاتِ وقبلَ كتابةِ صفِّ التشغيلة:

```php
foreach ($this->container->tagged('compliance.per_user_caps') as $capper) {
    if (! $capper instanceof EnforcesPerUserCaps) { continue; }

    for ($batch = 0; $batch < self::MAX_BATCHES_PER_CATEGORY; $batch++) {
        $done = $capper->enforceCaps(self::BATCH, $exemptUserIds);
        $rows[ExpiryBehaviour::Delete->value] += $done;
        if ($done < self::BATCH) { break; }
    }
}
```

⛔ **وترتيبُه بعدَ التجهيلِ مقصود**: المعكوسُ يُنفِقُ عملاً على تجهيلِ صفوفٍ يحذفُها السقفُ بعدَ لحظة.

⚠️ **ويُلَفُّ بـ`try/catch` مثلَ الفئات**: سقوطُ مُنفِّذٍ واحدٍ لا يُسقِطُ صفَّ التشغيلةِ نفسَه — وسجلٌّ لا يُكتَبُ لا يُفرَّقُ فيه بينَ «لا عملَ الليلة» و«لم تعمَلِ المكنسةُ منذُ مارس»، وهو السؤالُ الوحيدُ الذي يُفتَحُ هذا الجدولُ لأجلِه.

⚠️ **ولا قفلَ جديد**: `WithoutOverlapping` مع `expireAfter()` القائمُ يُغطّي المهمّةَ كلَّها بمرورَيها.
