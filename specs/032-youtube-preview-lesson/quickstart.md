# Quickstart — كيفَ يُثبَتُ أنّ ٠٣٢ تعمل

**Feature**: 032 · الحصّةُ التعريفيّةُ المجّانيّةُ مُستضافةٌ عندَ يوتيوب

كلُّ سيناريو هنا **يُشغَّلُ فعلاً** ويُقابِلُ معياراً في المواصفة. التفاصيلُ في
[`contracts/`](./contracts/) و[`data-model.md`](./data-model.md)؛ هذا ملفُّ تشغيلٍ لا تصميم.

## المتطلّبات

```bash
cd backend  && php artisan migrate          # هجرتان: العمودان، ثمّ backfill القالب
cd frontend && npm run dev                  # :3000 → :8000
```

⚠️ **لا `migrate:fresh`** — إضافةُ عمودَينِ nullable؛ و`seedMissing()` في هجرةِ القالبِ تكتبُ ما
ينقصُ بلا مساسٍ بما عدَّلَه مشغِّل.

## البوّابات

```bash
cd backend  && ./vendor/bin/pint --test
cd backend  && ./vendor/bin/phpstan analyse
cd backend  && php vendor/bin/pest tests/Feature/Courses tests/Feature/Marketplace tests/Feature/Learning
cd frontend && npx tsc --noEmit && npm test
```

⚠️ **دفعةٌ واحدةٌ في النهاية، لا بعدَ كلِّ ملفّ.** ولا تشغّلْ طقمَي pest متزامنَين — يتقاسمانِ
قرصَ الاختبارِ فيفتعلانِ فشلاً. والطقمُ الكاملُ شأنُ CI.

## السيناريوهات

### ١ — `SC-001` · حصّةٌ تُشاهَدُ بلا بايتٍ من تخزينِنا

```bash
php vendor/bin/pest --filter="creates no media asset and issues no grant"
```

يُنشَأُ درسٌ `embed` مفتوحٌ ويُنشَرُ ويُفتَح. **التوكيدةُ موجَبةٌ وسالبةٌ معاً**: `media_assets`
صفرُ صفوفٍ للدرس، ولا صفَّ في `playback_grants` — ومعَها توكيدةٌ أنّ الحمولةَ حملَتْ
`embed_url`، إذ نفيٌ وحدَه يمرُّ على تنفيذٍ لا يفعلُ شيئاً أصلاً.

### ٢ — `SC-002` · الزائرُ يُشاهِدُ بلا حساب

```bash
php vendor/bin/pest --filter="a guest reads an open embedded lesson"
```

`getJson()` **بلا `Sanctum::actingAs`** ⇒ `200` + `embed_url`.

⚠️ الحالةُ التي تفشلُ إن غابَ التجاوز: **مدرّسٌ من مساحةٍ أخرى مسجَّلُ الدخول** يفتحُ الرابط.
سياقُه يُحَلُّ من `last_workspace_id` فيعضُّ النطاق، بينما الزائرُ يقرأُ بنجاحٍ **سواءٌ وُجِدَ
الحارسُ أم لا** — فملفٌّ بحالةِ الزائرِ وحدَها لا يُثبِتُ شيئاً. (سابقةُ `DesignScopeBypassTest`.)

### ٣ — `SC-004` · جوابٌ واحدٌ لكلِّ رفض

```bash
php vendor/bin/pest --filter="every refusal is byte-identical"
```

سبعُ حالاتٍ في حلقةٍ واحدة: uuid لا وجودَ له · درسٌ مقفَل · كورسٌ مسوّدة · مدرّسٌ غيرُ مُدرَج ·
**درسُ فيديو مرفوعٌ مفتوح** · **درسٌ منشورٌ في قسمٍ مسوّدة** · كورسٌ محذوف. **يُقارَنُ
`getContent()` نفسُه** لا الرمزُ وحدَه.

⚠️ والحالةُ السادسةُ هي التي تفشلُ إن اشترطَ الاستعلامُ حالةَ الدرسِ وحدَها بدلَ
`visibleToStudents()` — وهي التي تُبقي رابطاً عامّاً يعملُ إلى الأبد بعدَ سحبِ نشرِ القسم.

### ٤ — `SC-003` · لا درسَ مُضمَّنٍ منشورٌ مقفَل

```bash
php vendor/bin/pest --filter="refuses to publish a locked embedded lesson"
```

**بابانِ لا ثلاثة**: النشرُ · نزعُ العلامةِ عن منشور. وحالةٌ ثالثةٌ تُثبِتُ أنّ إطفاءَ
`is_preview` وحدَه بينما `is_free` مضاءٌ **يُقبَل**.

⛔ **و«تحويلُ منشورٍ مقفَلٍ إلى مُضمَّن» ليست حالةَ اختبارٍ لهذه المواصفة**: `ChangeLessonType:157`
يرفضُ تغييرَ نوعِ **أيِّ** منشورٍ سلفاً، فالحالةُ خضراءُ قبلَ أن يُكتَبَ سطر. إن كُتِبَت فلتكنْ
مُعلَّمةً أنّها تعضُّ **الحارسَ القائم**، ورسالتُها المتوقَّعةُ رسالتُه هو.

⚠️ **وحالةُ العطبِ الخلفيّ، وهي أهمُّها**: أنشئْ درسَ `link` بعنوانٍ خارجَ الطقم ← حوِّلْه إلى
`embed` وهو مسوّدة ← تحقّقْ أنّ `external_url` **لم يعدْ** ذلك العنوان. بدونَها يمرُّ نصٌّ حرٌّ
إلى `iframe src` على صفحةٍ عامّة.

⚠️ **ولكلِّ حالةٍ فِخاخُها الخاصّة**: احذفْ شرطَ «المفتوح» وأعِدِ التشغيلَ — إن بقيَ ملفٌّ
أخضرَ فهو يقيسُ الحقلَ الناقصَ لا القاعدة. (سابقةُ `US6` في ٠١٣: تسعُ حالاتٍ خضراءَ بعدَ حذفِ
الحارسِ الذي كُتِبَت له.)

### ٥ — `SC-005` · التقدُّمُ يبلغُ ١٠٠٪ وتصدرُ الشهادة

```bash
php vendor/bin/pest --filter="an embedded lesson completes and the course certifies"
```

كورسٌ فيه درسٌ مُضمَّنٌ ومقالة؛ يُتِمُّ الطالبُ الاثنَينِ عبرَ
`POST /enrollments/{e}/lessons/{l}/complete` ⇒ `progress_pct = 100` · `CourseCompleted` ·
صفٌّ في `certificates`. **أهمُّ اختبارٍ في الميزة**: عكسُه هو أسوأُ عطبٍ في المستودَع.

### ٦ — `SC-009` · مضيفٌ خارجُ الطقمِ يُرفَضُ على الخادم

```bash
php vendor/bin/pest --filter="the closed host set is enforced server-side"
```

طلبٌ **مباشرٌ** لا نموذجٌ على شاشة، بجدولِ حالاتٍ من `contracts/embedded-lesson-type.md` —
`http://` · dailymotion · `javascript:` · معرِّفٌ قصير · نصٌّ ليسَ رابطاً ⇒ `422` كلُّها.

### ٧ — `SC-011` · مئةُ بلاغٍ ⇒ تنبيهٌ واحد

```bash
php vendor/bin/pest --filter="a hundred reports send one notification"
```

مئةُ `postJson` **من بصمةٍ واحدة** ⇒ صفٌّ واحدٌ في `notifications` لكلِّ مستقبِل، والجوابُ المئةُ
مطابقٌ للأوّل. ثمّ يُقدَّمُ الختمُ خمساً وعشرينَ ساعةً ⇒ تنبيهٌ ثانٍ. ثمّ يُحدَّثُ `external_url`
⇒ الختمُ `null` ⇒ تنبيهٌ فوريّ. **ويُختبَرُ أنّ تعديلَ العنوانِ وحدَه لا يمسحُ الختم.**

⛔ **والمرآةُ إلزاميّة**: بعدَ مئةِ بلاغٍ من بصمةٍ واحدة، **بلاغٌ من بصمةٍ ثانيةٍ داخلَ النافذةِ
يجبُ أن يُنبِّه**. بدونَها ضغطةٌ كاذبةٌ واحدةٌ تُطفئُ المستشعِرَ الوحيدَ أربعاً وعشرينَ ساعة.

⚠️ **وأشدُّ ما في هذا الملفّ**: الاختبارُ يجبُ أن **يُصفِّرَ معرِّفَ فريقِ spatie** قبلَ الطلب.
`asGuest()` يستبدلُ مفردةَ السياقِ ولا يمسحُ المعرِّفَ الذي زرعَه بناءُ المساحة — فبدونَ التصفيرِ
يقيسُ الاختبارُ طلباً لا تُرسِلُه المنصّةُ أبداً، وقراءةُ الصلاحيّةِ من طلبِ زائرٍ حقيقيٍّ تُجيبُ
«لا أحد».

⚠️ **ولا `Queue::fake()` عارية** — مستمعُ الإرسالِ مُطابَرٌ، فقاعدةٌ عاريةٌ تبتلعُه وتصيرُ
التوكيدةُ ادّعاءً واثقاً عن جدولٍ فارغ.

### ٨ — `SC-006` · لا حقلَ خارجَ المُصرَّحِ به

```bash
php vendor/bin/pest --filter=PublicExposureTest
```

⛔ **وهذا الحارسُ لا يعضُّ كما هو، وقد قِيسَ**: الاختبارُ يبني **اتّحاداً مسطَّحاً** من كلِّ
الثوابتِ ويُطابِقُ الأسماءَ في أيِّ عمق، و`uuid` فيه سلفاً — فإضافتُه لا تُحمِّرُه أبداً.
وتجهيزتُه درسٌ **مقفَلٌ** من نوعِ `article`، فالفرعُ الجديدُ لا يُدخَلُ أصلاً. والبابُ الجديدُ
ليسَ في `$payloads`.

**فثلاثةُ تعديلاتٍ قبلَ أن يعنيَ خُضرتُه شيئاً**: درسٌ مُضمَّنٌ مفتوحٌ في التجهيزة · البابُ
الجديدُ في `$payloads` · وتوكيدةٌ **بالمساواةِ** (`toEqualCanonicalizing`) على حمولةِ الدرسِ لا
بالاتّحاد. والأمرُ نفسُه لِـ`PublicCourseDetailTest` (توكيدةٌ دقيقةٌ على تجهيزةٍ مقفَلة) ولِـ
`PublicCourseBudgetTest` (كلُّ دروسِه مقفَلة، فلا يرى استعلاماً لكلِّ صفٍّ في الفرعِ الجديد).

### ٩ — `SC-007` · صفرُ نداءاتٍ للمستضيف

```bash
php vendor/bin/pest --filter="never calls the host"
```

`Http::preventStrayRequests()` حولَ الحفظِ والنشرِ والقراءةِ العامّةِ والبلاغ. وفي الواجهة،
اختبارُ vitest يُثبِتُ أنّ صفحةَ الدرسِ **لا تُحمِّلُ** نصّاً من `youtube.com` ولا `vimeo.com`
خارجَ `src` الإطار.

### ١٠ — الواجهة

```bash
cd frontend && npm test -- EmbedEditor EmbeddedVideo preview-lesson
```

- دعوةُ التسجيلِ مرسومةٌ **من أوّلِ رسم** بلا أيِّ حدثِ تشغيل (`FR-013`).
- `duration_seconds = 0` ⇒ **لا نصَّ مدّةٍ في المستند**، لا «٠ دقيقة» (`FR-018`).
- خيارُ «مُضمَّن» غائبٌ من المُنتقي لدرسٍ مقفَل (`FR-007`).
- المقياسُ **قائمةُ النداءات**: الصفحةُ العامّةُ تطرقُ بابَ السوقِ وحدَه ولا تطرقُ
  `/learn/lessons/…` أبداً — قاعدةٌ وهميّةٌ تقبلُ كلَّ مسارٍ تُخرِجُ شاشةً خضراءَ لا تقولُ شيئاً.
- ⛔ **وصفحةُ الطالبِ المسجَّلِ تُختبَرُ كذلك**: درسٌ `embed` يجبُ أن يرسمَ **إطاراً**، لا عنواناً
  وزرَّ إتمامٍ فوقَ بطاقةٍ فارغة. اليومَ فيها ستّةُ فروعٍ للأنواعِ ولا واحدَ منها `embed`، فالحالةُ
  تفشلُ قبلَ أن تُكتَبَ الشيفرة — وهذا هو المقصود.
- **`may_self_complete`** هو المفتاح، لا `is_self_completable`: محرفٌ واحدٌ يعني زرّاً لا يُرسَمُ
  أبداً بلا خطأ.

## المشيُ اليدويُّ (خمسُ دقائق)

1. `/manage/courses/{uuid}/content` → عنصرٌ جديد → **علّمْه «تعريفيّ» أوّلاً** (العنصرُ يُخلَقُ
   مقفَلاً، والخيارُ محجوبٌ عن المقفَل) → اختر «فيديو مُضمَّن» → الصقْ رابطَ يوتيوبَ واكتبِ
   المدّةَ → احفظ.
2. انزعْ «تعريفيّ» → **انشرْ فيُرفَض** برسالةٍ تقولُ ما العمل. أعِدْها → انشرْ فيُقبَل.
3. افتحْ نافذةَ تصفُّحٍ خاصّةً (بلا حساب) → `/courses/{slug}` → الحصّةُ وحدَها قابلةٌ للضغط →
   اضغطْها → **الفيديو يعمل**، ودعوةُ التسجيلِ بجانبِه.
4. اضغطْ «الفيديو لا يعمل» → افتحْ جرسَ المدرّسِ → تنبيهٌ واحد. اضغطْ ثانيةً → **لا ثاني**.
5. سجّلْ دخولَك طالباً مسجَّلاً وافتحِ الدرسَ من «تعلّمي» → **الفيديو يعملُ هناك أيضاً**، وتحتَه
   زرُّ «علِّمه مكتملاً» وسطرُ الإبلاغ. (بطاقةٌ فارغةٌ هنا تعني أنّ فرعَ `embed` لم يُكتَب.)

⚠️ تغييرٌ محفوظٌ لا يظهر؟ `Ctrl+Shift+R` — القطعةُ بائتةٌ في المتصفّح، لا الخادمُ.
