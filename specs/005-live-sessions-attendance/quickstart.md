# Quickstart — التحقّق من الحصص المباشرة والحضور والتجميد

**Feature**: `005-live-sessions-attendance`

سيناريوهات تُنفَّذ كما هي وتثبت أن المرحلة تعمل من طرف إلى طرف. كل واحد يذكر ما يُتوقَّع
بالضبط، لأن «مرّ» بلا توقّع مكتوب ليس تحقّقاً.

---

## المتطلّبات

```bash
cd backend
php artisan migrate:fresh --seed        # يشمل PlatformSettingsSeeder و NotificationTemplateSeeder
PHP_CLI_SERVER_WORKERS=8 php artisan serve
```

`PHP_CLI_SERVER_WORKERS=8` ليس زينة: خادم PHP المدمج بخيط واحد، وبناء الواجهة للإنتاج
يستدعي الـAPI من عدة عمّال متوازين أثناء التوليد المسبق — فيفشل **البناء** قبل أن يبدأ أي
اختبار. (مزلق مدوَّن في `CLAUDE.md`.)

```bash
cd frontend && npm run dev              # ولا تشغّل build وdev معاً — كلاهما يكتب في .next/
```

المزوّد المربوط محلياً `NullBroadcastProvider`: غرفة وتذاكر بلا بثّ. **هذا كافٍ لكل شيء عدا
الفيديو نفسه** — لأن الحضور لا يمرّ بالمزوّد أصلاً.

---

## 1. الجدولة والحجز (US1)

```bash
php artisan tinker --execute="…"   # أو من الواجهة: /manage/sessions
```

1. من `/manage/sessions` اختر مدى تاريخياً واضغط **توليد من جدول التوفّر**.
   **المتوقّع**: حصص بمواعيد ومدد ومقاعد، ولائحة بما تُخطّي **مع سببه**.
2. حاول إنشاء حصة تتداخل مع أخرى للمدرّس نفسه.
   **المتوقّع**: ٤٢٢ بنصّ عربي تحت الحقل — لا خطأ خام (FR-003).
3. من حساب طالب، افتح `/schedule`، احجز مقعداً.
   **المتوقّع**: ينقص الشاغر، وتظهر الحصة في جدوله، ويبدأ العدّاد التنازلي.
4. املأ المقاعد ثم احجز بطالب إضافي.
   **المتوقّع**: ٤٠٩ مع بيان أن المقاعد اكتملت (FR-008).

**التزامن (SC-001)** — يُثبَت باختبار لا بالمتصفّح:

```bash
php vendor/bin/pest --filter="لا يتجاوز عدد المحجوزين عدد المقاعد"
```

الحارس تحديث شرطي ذرّي (`WHERE seats_taken < seats_total`) لا `lockForUpdate` — الأخير بلا
أثر على SQLite، فاختباره يمرّ محلياً ولا يثبت شيئاً عن MySQL.

---

## 2. الغرفة والحضور (US2 · US3)

1. في موعد الحصة افتح `/sessions/{uuid}/room` من حساب المدرّس ثم من حساب طالب حاجز.
   **المتوقّع**: تذكرة دخول لكلٍّ منهما، وحلقة النبض تعمل (تفقّد شبكة المتصفّح: نداء كل ٣٠ث).
2. افتح المسار نفسه من حساب لم يحجز.
   **المتوقّع**: ٤٠٣ **بلا كشف أي معلومة عن الحصة** (FR-015).
3. اترك الطالب في الغرفة، ثم افتح `/manage/sessions/{uuid}`.
   **المتوقّع**: `stay_seconds` يتزايد، والحالة `present` بعد بلوغ المدة المطلوبة.
4. افتح الغرفة نفسها من جهاز ثانٍ للطالب نفسه في الوقت نفسه.
   **المتوقّع**: المدة **لا تتضاعف** (FR-024) — النبضة تضيف الفارق منذ آخر نبضة من أي جهاز.
5. أغلق الغرفة من المدرّس.
   **المتوقّع**: **يُمنع** الدخول بأي تذكرة سابقة (FR-015).

**السُّلَّم الزمني والعتبة** — بالساعة المزيّفة لا بالانتظار:

```bash
php vendor/bin/pest tests/Feature/LiveSessions/AttendanceLadderTest.php
```

يغطّي المواضع الأربعة (SC-020) و**لحظة** كتابة `Absent` (SC-021): عند انقضاء العتبة، لا عند
نهاية الحصة.

## 3. التسجيل يصبح درساً (US4)

`NullBroadcastProvider` لا يسجّل، فهذه القصة تُتحقَّق باختبار على `FakeBroadcastProvider`:

```bash
php vendor/bin/pest tests/Feature/LiveSessions/RecordingPublicationTest.php
```

**المتوقّع**: `MediaAsset` يُنشأ → `MediaAssetReady` → درس مرتبط بالحصة → من حجز مقعداً
يشاهده بكل ضوابط 004، ومن لم يحجز **يُمنع** (SC-008). حالة «قيد التجهيز» تُعرض ولا تفشل.

**ما لا يُثبَت هنا**: أن مزوّداً حقيقياً ينتج ملفاً حقيقياً. مكتوب صراحةً في جدول
*Deferred Verification* في `plan.md`.

## 4. التقرير والتجميد (US5 · US6)

```bash
php vendor/bin/pest --filter="تقرير ما بعد الحصة"
php vendor/bin/pest --filter="تجميد"
```

**المتوقّع في التقرير**: يصل وليَّي أمر الطالب معاً ويُسجَّل **مرة واحدة**، ويصل الطالب نفسه
إن لم يوجد وليّ أمر، ولا يتأخّر انتظاراً لتقييم لم يُدخَل، ويحترم تفضيلات الإشعارات.

> **تنبيه**: كل نوع إشعار جديد يحتاج قالباً في `NotificationTemplateSeeder`. بلا قالب يسقط
> الإشعار **صامتاً** ويمرّ الاختبار على صفر إشعارات فيبدو أخضر.

**المتوقّع في التجميد**: صفر حصة جديدة داخل الفترة، وتعليق المجدولة مع إبلاغ من حجز، وصفر
غياب محتسَب، وصفر عدّاد متقدّم — ثم استئناف بالقيم نفسها بلا فقدان.

---

## 5. الوصول — إلزامي قبل إعلان الإنجاز

الخطأ الذي وقع مرتين: شاشة موجودة ولا شيء يربطها. كل شاشة جديدة تُختبَر **بالدخول إليها من
التنقّل**، لا بكتابة رابطها:

```bash
cd frontend && npx playwright test e2e/sessions.spec.ts
```

**المتوقّع**: الشريط الجانبي → جدولي → حصة → الغرفة، وللمدرّس: الشريط → حصصي → حصة → كشف
الحضور. اختبار يفتح الرابط مباشرةً **لا يثبت أن الطريق موجود**.
