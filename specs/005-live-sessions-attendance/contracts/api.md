# API Contract — الحصص المباشرة والحضور والتجميد

**Feature**: `005-live-sessions-attendance` · كل المسارات تحت `/api/v1`

قواعد سارية على الجدول كلّه: مصادقة Sanctum · كشف `uuid` فقط لا المعرّف التسلسلي (المبدأ VI)
· كل استجابة عبر API Resource · كل مسار كتابة محدود المعدّل بمحدِّد **مُسمّى** (الإدراج
النصّي `throttle:5,1` ممنوع — يتشارك عدّاداً واحداً مع كل حدّ مضمّن آخر).

**محدِّد جديد**: `throttle:sessions` — `60/دقيقة` بالمستخدم للحجز وإصدار التذاكر،
و`240/دقيقة` بالمستخدم للنبض (نبضة كل ٣٠ ثانية = ٢/دقيقة للمشارك الواحد؛ السقف يترك مجالاً
لعدة غرف وإعادة اتصال بلا أن يفتح باباً).

---

## جدولة الحصص — المدرّس

| المسار | الطريقة | الصلاحية | ملاحظات |
|---|---|---|---|
| `/class-sessions` | GET | `sessions.view` | مُرشَّح بالمدى والحالة؛ عدد استعلامات ثابت (SC-011) |
| `/class-sessions` | POST | `sessions.manage` | حصة واحدة؛ 422 عند التداخل (FR-003) |
| `/class-sessions/generate` | POST | `sessions.manage` | توليد من جدول التوفّر لمدى تاريخي (FR-002) |
| `/class-sessions/{uuid}` | GET | `sessions.view` | تفاصيل + المقاعد + الكشف إن أُغلقت |
| `/class-sessions/{uuid}` | PUT | `sessions.manage` | **يُمنع** تغيير `type` بعد وجود حجز (FR-001ب) |
| `/class-sessions/{uuid}/cancel` | POST | `sessions.manage` | يُبلَّغ كل من حجز (FR-006) |

**التوليد**: يقبل `from` و`to` و`slot_uuids?`، ويُرجع ما أُنشئ وما تُخطّي **مع سببه** —
حصة متداخلة أو واقعة داخل تجميد تُذكر بالاسم، لا تُبتلع صامتة.

## الحجز — الطالب

| المسار | الطريقة | ملاحظات |
|---|---|---|
| `/class-sessions/{uuid}/book` | POST | تحديث شرطي ذرّي؛ 409 عند امتلاء المقاعد **مع بيان السبب** (FR-007 · FR-008) |
| `/bookings/{uuid}` | DELETE | قبل المهلة يحرّر المقعد؛ بعدها يُحتسب ويُعلَّم `cancelled_late` (FR-009 · FR-010) |
| `/schedule` | GET | **جدول الطالب الموحّد عبر كل مدرّسيه** (FR-052) |
| `/schedule/next` | GET | الحصة القادمة + الوقت المتبقّي بالثواني (FR-053) |

**`/schedule` مسار قراءة مملوك للمنصة** — عابر لمساحات العمل عمداً، حارسه ملكية الطالب
للصفوف. **يُمنع** أن يكشف للمدرّس حصص طالبه عند غيره؛ اختبار مخصّص يثبت الاتجاهين.

**العدّاد التنازلي** يُبنى من `starts_at` وثوانٍ متبقّية من الخادم — لا من ساعة المتصفّح
(SC-016). ساعة العميل قابلة للانحراف والتزوير، وعدّاد يعتمد عليها يعرض موعداً لا يوجد.

## غرفة البث

| المسار | الطريقة | ملاحظات |
|---|---|---|
| `/class-sessions/{uuid}/join` | POST | تذكرة قصيرة العمر؛ **الأهلية تُعاد تقييمها هنا** (FR-046) |
| `/class-sessions/{uuid}/presence` | POST | النبض — مصدر الحضور (R3) |
| `/class-sessions/{uuid}/host/{action}` | POST | `mute` · `remove` · `end` — `sessions.host` فقط |

**الإغلاق المبكّر** هو `host/end` ولا مسار ثانٍ له. كان `/leave` مُعلَناً هنا ثم حُذف عند
مراجعة الوصول: تفويضه `sessions.host` وأثره إغلاق الغرفة — أي هو `host/end` باسم يوحي
للطالب أنه له، ومسار مكرّر لا يناديه أحد باسم مضلِّل أسوأ من غيابه.

**رفض الدخول** يعيد 403 **بلا كشف أي معلومة عن الحصة** (FR-015 · السيناريو 2): من لم يحجز
لا يعرف من الردّ أن الحصة موجودة أصلاً.

**النبض** يقبل جسماً فارغاً ويعيد `{stay_seconds, status, session_status}` — العميل يعرض،
والخادم يقرّر. الفارق يُحتسب من `last_ping_at` بسقف `2 × interval`، فجهازان لا يضاعفان
المدة (FR-024).

**التذكرة** لا تحمل مفتاح مزوّد ولا سرّه (FR-019) — تحمل `room_url` و`token` و`expires_at`
و`role`. المزوّد نفسه لا يُذكر باسمه في أي حمولة.

## الحضور

| المسار | الطريقة | الصلاحية | ملاحظات |
|---|---|---|---|
| `/class-sessions/{uuid}/attendance` | GET | `attendance.view` | الكشف الكامل — **كل مقعد مُجمَّد بلا استثناء** (FR-023أ · SC-022) |
| `/attendances/{uuid}/override` | POST | `attendance.override` | داخل النافذة؛ بعدها 403 بـ`code: attendance_window_closed` (FR-022ب) |
| `/class-sessions/{uuid}/feedback` | POST | `sessions.manage` | تقييم موجز لكل طالب (FR-036) |
| `/students/{uuid}/attendance` | GET | ملكية أو ولاية | الطالب صفّه، ووليّه صفّ ابنه وحده (FR-023ب) |

**التعديل** يُرجع الصفّ ومعه `auto_status` الأصلي ظاهراً — المصدر الآلي لا يُمحى (FR-025)،
لأن كشفاً لا يُظهر أنه عُدِّل هو كشف يُصدَّق أكثر مما يستحق.

**رمز الخطأ** `attendance_window_closed` يُضاف إلى `BY_CODE` في `frontend/src/lib/errors.ts`
— **يُمنع** عرض خطأ خام للمستخدم.

## أشكال الاستجابة

```jsonc
// GET /class-sessions/{uuid}
{
  "uuid": "…", "title": "…", "type": "group", "status": "scheduled",
  "starts_at": "2026-08-10T15:00:00Z", "ends_at": "2026-08-10T16:00:00Z",
  "duration_minutes": 60, "timezone": "Asia/Qatar",
  "seats": { "total": 8, "taken": 5, "available": 3 },
  "my_booking": { "uuid": "…", "status": "booked", "may_cancel_until": "2026-08-09T15:00:00Z" },
  "recording": { "status": "published", "lesson_uuid": "…" }
  // لا broadcast_provider، ولا broadcast_room_id، ولا معرّف تسلسلي واحد
}

// POST /class-sessions/{uuid}/presence
{ "stay_seconds": 1320, "status": "present", "session_status": "live" }
```

`billable_seats` **لا يظهر للطالب** — رقم محاسبي يخصّ المدرّس والإدارة، وكشفه للطالب يدعو
سؤالاً عن فاتورة لم تُرسَل بعد.
