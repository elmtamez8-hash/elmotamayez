# العقد: `CurrentAuthSession`

**الموضع**: `backend/app/Shared/Contracts/CurrentAuthSession.php` · **المُنفِّذ**: `Identity` · **المُنادونَ**: `Media` · `Store`

---

## السؤالُ الذي يُجيبُ عنه

«أيُّ صفٍّ في `auth_sessions` يُصادِقُ **هذا الطلبَ الآن**؟»

وهو سؤالٌ واحدٌ له بابانِ، ولذلك يُكتَبُ مرّةً واحدة.

---

## الشكل

```php
interface CurrentAuthSession
{
    /**
     * الجلسةُ التي يُصادَقُ بها هذا الطلب، أو null لغيرِ المصادَق.
     *
     * ⛔ تُجيبُ عن البابَين: الرمزِ والجلسة. والقارئُ لا يسألُ أيَّهما —
     * وأيُّ فرعٍ عندَ المُنادي على «هل معه رمز» هو تهجئةٌ ثانيةٌ لهذا السؤال.
     */
    public function forRequest(Request $request): ?AuthSessionSnapshot;
}
```

```php
final readonly class AuthSessionSnapshot
{
    public function __construct(
        public int $id,
        public string $uuid,
        public int $userId,
        public ?int $deviceId,
    ) {}
}
```

---

## لماذا لقطةٌ لا موديل

`Media` و`Store` يحتاجانِ المُعرِّفَ ليربِطا به — لا صفَّ `Identity` بكلِّ حقولِه. وعقدٌ يُعيدُ موديلَ وحدةٍ أخرى **هو المبدأُ III مخروقاً بأدبٍ أكثر**: الاستيرادُ يختفي من رأسِ الملفِّ ويبقى الاقترانُ كما هو.

⚠️ **و`MintPlaybackGrant::handle()` يأخذُ `AuthSession` اليوم.** فإمّا أن يأخذَ اللقطةَ، أو يُحَلَّ الصفُّ داخلَ `Identity` ويُمرَّر. **والأوّلُ هو الصحيح**: المنحةُ تحتاجُ `auth_session_id` وحدَه، والموديلُ هناك تَرَفٌ يُبقي الحدودَ مفتوحة.

## العقدُ السلوكيّ — ما يجبُ أن يبقى صحيحاً

| # | القاعدة | لماذا |
|---|---|---|
| ١ | يُجيبُ للمصادَقِ **بأيِّ** وسيلة | بدونِها: `401` على كلِّ تشغيلٍ وكلِّ مشترىً لمن دخلَ بجلسة (`research.md` · التصحيح ١) |
| ٢ | يُجيبُ بـ`null` لغيرِ المصادَق — **ولا يرمي** | المُنادي يقرّرُ الرفض؛ استثناءٌ هنا يجعلُ كلَّ منادٍ يكتبُ `try` |
| ٣ | يقرأُ الجلساتِ **النشطةَ وحدَها** | جلسةٌ أُنهِيَت ليست جلسةَ هذا الطلب — وهذا هو الطردُ ذاتُه |
| ٤ | لا يكتبُ شيئاً | قراءةٌ تكتبُ تُفاجئُ كلَّ منادٍ، وهذه تُنادى في كلِّ تشغيل |
| ٥ | **استعلامٌ واحدٌ لكلِّ طلب** | يُنادى على مسارِ التشغيلِ الساخن؛ وسقفُ `QueryBudgetTest` هو القياس |

## ما يُقاسُ بحذفِه (FR-004)

| ما يُحذَف | ما يجبُ أن يسقط |
|---|---|
| فرعُ `session_id` من المُنفِّذ | حالةُ «تشغيلٌ بجلسةٍ ⇒ ٢٠٠» تصيرُ `401` |
| شرطُ `active()` | حالةُ «جلسةٌ أُنهِيَت ⇒ رفض» تصيرُ نجاحاً |

⚠️ **وحارسٌ يبقى أخضرَ بعدَ حذفِ ما يحرسُه ليسَ حارساً.** القياسُ إجباريٌّ لا استنتاجيّ — وهو نصُّ `SC-004`.

## العقدُ الظاهرُ الذي يُقلَب: مصادقةُ الـAPI

`config/sanctum.php` → `'guard' => ['web']`.

⛔ **و`ApiIsBearerOnlyTest` يُقلَبُ ولا يُحذَف.** حارسٌ يُحذَفُ في الطلبِ الذي يغيّرُ ما يحرسُه هو الشكلُ الذي يمرُّ منه عطبٌ حقيقيٌّ باسمِ «تحديثِ التوكيدات»؛ يُكتَبُ فيه أنّ الانقلابَ **بقرارٍ مؤرَّخٍ** لا باجتهادِ قارئ. وحالتُه الثالثةُ — «جلسةٌ لا تُنقِذُ رمزاً مُبطَلاً» — **تبقى صحيحةً بعدَ القلبِ ولا تُمَسّ**: رمزٌ مُبطَلٌ يبقى مُبطَلاً أيّاً كانَ ما يُصادِقُ بجوارِه.

**والترتيبُ شرطٌ في العقدِ لا نصيحة**: هذا السطرُ آخرُ ما يُقلَب.
